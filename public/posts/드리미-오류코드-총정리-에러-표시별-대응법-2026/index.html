## 🔧 센서 관련 오류코드

![센서 관련 오류코드](/images/auto_1788917045_section2_844874.jpg)


### E01: 메인 브러시 막힘
리뷰 데이터를 살펴보면 가장 빈번한 오류예요. 머리카락이나 실밥이 브러시에 엉켜서 발생해요.

**즉시 대응법:**
1. 메인 브러시 커버 분리
2. 엉킨 이물질 제거 (제공 클리닝 툴 사용)
3. 베어링 부분까지 확인
4. 재장착 후 재시작

구매자들이 공통적으로 언급하는 예방법은 주 1회 브러시 청소예요.

### E02: 사이드 브러시 오류
사이드 브러시가 움직이지 않거나 회전 속도가 느려질 때 발생해요. 수집된 후기 패턴을 보면 먼지 축적이 주원인이에요.

**해결 단계:**
- 브러시 탈거 후 축 청소
- 회전 모터 부위 먼지 제거
- 브러시 마모 상태 확인 (6개월 이상 사용 시 교체 권장)

## 🧭 네비게이션 오류코드

![네비게이션 오류코드](/images/auto_1788917045_section3_35147280.jpg)


### E03: LDS 센서 막힘
천장 매핑용 레이저 센서에 먼지가 쌓여 발생해요. 후기를 종합해보면 고양이털이 많은 집에서 자주 나타나요.

**청소 방법:**
1. 상단 LDS 커버 회전 후 분리
2. 마른 극세사 천으로 센서 유리 닦기
3. 압축 공기로 틈새 먼지 제거
4. 커버 재장착

*"센서 청소는 안경 닦듯이 부드럽게! 스크래치 나면 맵핑이 영화 '미션 임파서블'처럼 돼요 🕶️"*

### E04: 절벽 감지 센서 오류
낙하 방지 센서에 이물질이 묻거나 어두운 바닥을 절벽으로 오인할 때 나타나요.

**대응 체크리스트:**
- 하단 센서 4개소 마른 천으로 닦기
- 검은색 러그나 유리 테이블 근처에서 빈발하는지 확인
- 가상벽 설정으로 해당 구역 회피

## 🔋 배터리 관련 오류코드

### E05: 충전 실패
충전대 접촉 불량이나 배터리 수명 문제예요. 후기를 종합해보면, 2년 이상 사용 제품에서 증가하는 추세예요.

**단계별 점검:**
1. 충전대 접점 알코올 솜으로 닦기
2. 로봇 하단 충전 단자 청소
3. 다른 콘센트에서 충전 시도
4. 배터리 수명 확인 (앱에서 건강도 체크)

### E06: 과열 보호
장시간 청소나 고온 환경에서 배터리 온도가 상승하면 발동돼요.

**즉시 조치:**
- 전원 OFF 후 30분 냉각
- 환기된 그늘진 곳에 배치
- 여름철 직사광선 노출 구역 청소 시간대 변경

## 🌐 통신·앱 연동 오류코드

### C01: Wi-Fi 연결 끊김
수백 건의 후기를 분석해보면 공유기 재부팅만으로 80% 해결돼요.

**해결 순서:**
1. 공유기 재부팅 (30초 대기)
2. 로봇 Wi-Fi 설정 재등록
3. 2.4GHz 대역 사용 확인 (5GHz 미지원 모델 多)
4. 펌웨어 최신 버전 확인

### C02: 앱 동기화 오류
클라우드 서버와의 연결 문제예요. 리뷰 데이터를 살펴보면 새벽 시간대 서버 점검과 겹칠 때 간혹 발생해요.

**대응:**
- 앱 강제 종료 후 재실행
- 로그아웃/로그인
- 앱 삭제 후 재설치 (최후 수단)

## ⚠️ 물리적 장애 오류코드

### E07: 바퀴 공회전
바퀴에 털이 감기거나 문턱에 걸렸을 때 발생해요. 구매자들이 공통적으로 언급하는 빈발 지점은 현관 문턱이에요.

**점검 포인트:**
- 좌·우 바퀴 회전 상태 확인
- 축에 감긴 머리카락 제거
- 바퀴 고무 마모 확인 (2년 이상 사용 시)

### E08: 물통 장착 오류
물걸레 청소 시 물통 미장착이나 잠금 불량으로 나타나요.

**체크 사항:**
1. 물통 클릭 소리 확인
2. 물통 내부 센서 접점 청소
3. 고무 패킹 변형 여부 확인

*"물통은 '찰칵' 소리가 나야 제대로 장착된 거예요. 소리 없으면 청소기가 '물통 어디 갔어?' 하고 당황해요 💧"*

## 🛠️ 드리미 자가 진단 모드

앱에 표시되지 않는 이상 증상은 숨겨진 진단 모드로 확인할 수 있어요. 후기를 종합해보면 A/S 전 이 단계를 거치면 출장비를 아낄 수 있다는 평이 많아요.

**진단 모드 진입법:**
1. 전원 버튼 + 홈 버튼 동시에 5초 누름
2. 음성 안내 후 센서 테스트 시작
3. 화면에 표시되는 항목별 상태 확인
4. 오류 항목 메모 후 고객센터 문의

## 📞 고객센터 연락 전 준비사항

A/S 신청 전 이 정보를 준비하면 처리가 빨라요:

- 정확한 오류코드 번호
- 오류 발생 시점 (날짜·시간)
- 앱 화면 캡처
- 최근 소프트웨어 버전
- 구매 영수증 (보증 기간 확인용)

수백 건의 리뷰를 살펴보면, 이 정보를 미리 준비하면 평균 응대 시간이 40% 단축돼요.
