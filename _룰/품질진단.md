ⓐ 가격 자리에 실제 숫자가 없고 `일정 금액`·`가격대`·`쿠팡 현재가 기준 프리미엄` 같은 껍데기만 남음. 치환 실패로 문장 자체가 깨진 곳도 다수.
ⓑ "일정 금액/가격/수준" 24개 · "쿠팡 현재가 기준" 32개 · 가격 플레이스홀더 파손 22개
ⓒ 예: "kWh당 약 일정 금액예요" / "120~가격대에 구매했으며" / "~2일정 가격"
ⓓ 처방: 가격은 **수집 시점 명기한 실제 숫자**로 쓰고, 못 쓰면 그 문장을 통째로 삭제. "가격대 가격" 같은 잔재는 전수 grep으로 색출.

### ② 본문이 문장 중간에서 끊긴다 (미완성 배포)
ⓐ 글 끝 또는 항목 중간이 어절 단위로 절단. 발행된 상태.
ⓑ 명백한 절단 12~15개 (③추천 TOP N에 집중), 템플릿 칭찬 문장 절단 4개
ⓒ 예: "**추천" (로보락 vs 드리미, TOP 5인데 3위에서 끝남) / "드리미 L10S와 L40S는 10N 압" / "수백 건의 후"
ⓓ 처방: 배포 전 "마지막 문단이 종결어미로 끝나는가" 자동 검사. TOP N 글은 N개가 실제로 다 있는지 카운트 검증.

ⓒ 예: "센서 먼지 적립 42%" / "증류수 사용 시 석회질 문제가 90% 감소" / "고장률이 70% 낮았죠"

## 4. 유형별 현재 H2 구조 패턴

- **④ 후기·리뷰분석** (가장 정형화, 22개 동일): `📊 실구매자 150명이 지적한 점` → `한눈에 보는 핵심`(5축 점수표) → `실사용자가 만족한 점` → `아쉬운 점·주의사항` → `이런 분께 추천` → (16개만) `이런 분께는 비추천` → `경쟁 제품과 비교하면` → `총평` → `💰 유지비`
- **③ 추천 TOP N**: 순위 산정 기준 인용구 → `TOP 5 한눈에 비교` 표 → 1~5위 각각(왜 N위인가 / 장점 목록 / 주의할 점 / 이런 분께 추천 / 쿠팡 링크) → 항목별 비교 → 평수별 추천. **절단이 가장 많이 발생하는 유형.**
- **② 문제해결**: 도입(증상 공감) → 원인 분포 → 단계별/에러번호별 조치 → `🔧 그래도 안 되면 — 소모품 확인`(제휴) → 재발 방지 체크리스트 → `❓ 자주 묻는 질문` → `🛒 관련 제품`
- **⑤ 사용법·가이드**: 필요한 순간 → 브랜드별 절차 → 팁 N단계 → 원인·예방 → 부가 기능 → 마무리 체크리스트. **브랜드별 절차 블록이 이 유형의 실질 가치.**
- **① 스펙·출시**: `출시 개요` → `핵심 사양 한눈에`(표) → `어떤 형태인가` → `구매 전 짚어볼 점` → `누구에게 맞고, 누구에겐 아닌가` → (한 달 뒤) `🔄 한 달 실사용 후기` 추가. 6개 글이 이 골격을 공유, 가장 일관성 높음.

## 5. 가장 먼저 고칠 것 3가지 (효율 순)

1. **절단된 글 복구 + 가격 플레이스홀더 청소** — 약 35개 글, 기계적 작업. 신뢰도 손상이 가장 크고 고치는 비용은 가장 싸다. 배포 전 검사 2개(마지막 문장 종결 여부 / `일정 금액|가격대 가격|쿠팡 현재가 기준` grep)를 파이프라인에 넣으면 재발이 끊긴다.
2. **"수백 건의 후기를 분석해보면"(66개)을 실제 숫자로 교체** — 이 한 구절이 사이트 전체를 AI 생성물로 보이게 만드는 단일 최대 원인. `리뷰 N건(2026-08 수집) 기준` 형태로 바꾸고, 뒷받침 데이터가 없는 자리는 문장을 지운다. 무출처 %(13개)와 리뷰 건수 불일치(5개)도 같은 작업에서 처리.
3. **④ 리뷰 템플릿의 `이런 분께는 비추천`을 전 유형 필수 항목으로 승격** — 현재 29/127. ③추천 TOP N에는 특히 없다. "누구에게는 권하지 않는가"가 이 블로그가 제조사 스펙시트와 갈라지는 유일한 지점이고, 기존 템플릿에 한 블록 추가하는 것만으로 판단 선명도가 올라간다. 비추천 사유에 가격을 쓰지 않는다는 규칙을 함께 건다.
