## 먼저 알아 둘 것 — 규칙이 정한 시간

「공동주택 층간소음의 범위와 기준에 관한 규칙」(2023-01-02 개정)은 **주간을 06:00~22:00, 야간을 22:00~06:00**으로 나누고 기준을 따로 둡니다.

| 층간소음 구분 | 평가 방법 | 주간 (06~22시) | 야간 (22~06시) |
|---|---|---|---|
| 직접충격 소음 (뛰거나 걷는 동작 등) | 1분간 등가소음도 | 39 dB(A) | 34 dB(A) |
| | 최고소음도 | 57 dB(A) | 52 dB(A) |
| 공기전달 소음 (텔레비전, 음향기기 등) | 5분간 등가소음도 | 45 dB(A) | 40 dB(A) |

야간 기준이 주간보다 5dB 낮습니다. 규칙은 입주자가 이 기준 이하가 되도록 **노력하여야 한다**고 적습니다. 1분간 등가소음도 기준은 2023년 개정 때 주간 43→39dB, 야간 38→34dB로 낮아졌습니다.

**로봇청소기 소리는 어디에 들까요?** 층간소음 이웃사이센터 자주 묻는 질문은 보일러·냉장고·세탁기·**청소기** 같은 기계에서 나는 소음·진동을 층간소음 전문기관의 업무 범위 밖으로 둡니다. 다만 **청소기를 쓰면서 나는 마찰·충격·타격음은 제외**한다고 적습니다. 모터 소리 자체보다 로봇이 가구에 부딪히는 소리나 바닥을 긁는 소리가 문제가 될 수 있다는 뜻으로 읽힙니다. 로봇청소기를 따로 짚은 공식 해석은 찾지 못했습니다.

## 1. 예약은 낮에, 밤에는 방해 금지 모드

예약 청소는 규칙의 주간(06~22시) 안에 둡니다. 밤에 집에 사람이 있다면 앱의 **방해 금지 모드**(DND)를 켭니다. 이 모드에서 무엇이 멈추는지는 브랜드마다 다릅니다.

| 브랜드 | 기본 시간 | 방해 금지 시간에 하는 일 |
|---|---|---|
| 로보락 | **22:00~08:00** (S6·S8+·Qrevo Edge 2 등 설명서) | 멈췄던 청소를 **자동으로 이어 하지 않음**, 표시등 어둡게, 음성 작게. 도크로 돌아와도 **자동 먼지 비움을 하지 않음**(S8+). 앱에서 끄거나 시간을 바꿀 수 있다 |
| 드리미 | **22:00~8:00**, 출고 때는 **꺼져 있음** (L10s Ultra 한국어 설명서) | 청소를 다시 시작하지 않고 전원 표시등이 꺼짐. **예약 청소는 제시간에 한다** — 방해 금지 시간이 끝나면 멈췄던 곳부터 이어 한다 |
| 에코백스 | 확인 못 함 | **예약 청소를 실행하지 않음**, 스테이션에 돌아와도 **먼지를 비우지 않음**. 음성 알림이 거슬리면 방해 금지 모드를 켜라고 안내 |
| LG | 방해 금지 기능은 확인 못 함 | ThinQ 앱에서 **야간 자동 먼지 비움 금지**를 설정할 수 있다 |
| 삼성 | 공식 안내에서 확인 못 함 | — |

{{< callout kind="warn" title="드리미는 방해 금지 시간에도 예약 청소를 한다" >}}
드리미 L10s Ultra 설명서는 «DND 기간 동안 예정된 청소 작업을 정시에 실시합니다»라고 적습니다. 방해 금지 모드를 켜도 **밤으로 잡아 둔 예약은 그대로 돈다**는 뜻입니다. 밤 예약을 없애는 것이 먼저입니다.
{{< /callout >}}

## 2. 흡입력과 카펫 자동 터보

흡입력이 셀수록 소리도 커집니다. 앱에서 단계를 낮추고, 카펫을 만나면 저절로 세지는 기능을 확인합니다.

{{< check title="흡입력 설정 (로보락 · 드리미 · 에코백스 · LG · 삼성)" >}}
1. 흡입력을 **조용한 단계나 표준**으로 둔다 — 로보락 S6 는 Quiet·Balanced·Turbo·MAX 중 기본이 Balanced, 드리미 앱은 **저소음·표준·터보·맥스**이고 **구역별로** 따로 정할 수 있다
2. 에코백스 X5 PRO OMNI 설명서는 청소할 때 매우 큰 소음이 나는 원인으로 **최대 흡입 모드**를 들고 **표준 모드로 바꾸라**고 한다
3. LG R9 는 **스마트 터보**를 켜면 카펫이나 거친 바닥에서 흡입력을 스스로 올려 소리가 커질 수 있다 — 원하지 않으면 **리모컨이나 LG ThinQ 앱에서 해제**한다
4. 삼성 제트 봇 AI 는 흡입 세기를 **스마트**로 두었을 때만 바닥재에 따라 흡입력이 바뀐다. 2026 비스포크 AI 스팀은 스마트싱스 앱 **주행 세부 설정 → 카펫 청소**에서 카펫을 피해서 청소하는 방식 등을 고를 수 있다
{{< /check >}}

## 3. 음성 안내 줄이기

{{< check title="음성 끄기·줄이기 (LG · 드리미 · 에코백스)" >}}
1. LG 로봇청소기는 **리모컨의 음소거 버튼**으로 음소거한다. VR634*·VR635*·R45**·R55** 모델은 본체 **시작/정지 + 충전 버튼을 3초** 함께 누른다
2. LG 코드제로 M9 는 리모컨 음소거나 **LG ThinQ 앱 [설정]**에서 세부 음량을 바꾼다. 음소거 중에도 **에러 음성은 나온다**
3. 드리미는 앱에서 **음성 볼륨**을 정한다
4. 에코백스는 앱에서 **음성을 끄거나** 볼륨을 낮추고, 방해 금지 모드를 켜도 된다
{{< /check >}}

## 4. 먼지 비우는 소리

자동 먼지 비움 스테이션은 청소보다 소리가 큽니다. 로보락은 S9 MaxV Ultra 제품 페이지에 자체 시험 기준으로 **조용한 걸레질 모드 52dB(A), 도크 자동 비우기 72dB(A)**라고 적었습니다. LG도 **먼지 비움 중에 나는 소음은 정상적인 소음**이라고 안내하고, 삼성은 청정스테이션이 먼지를 비울 때 **먼지 배출 소음과 함께 흰색 LED**가 켜진다고 설명합니다. 고장이 아니라면 **언제 비우게 할지**를 정하는 것이 방법입니다.

{{< check title="먼지 비움 시간 정하기 (로보락 · 드리미 · LG · 에코백스)" >}}
1. **방해 금지 시간에는 비우지 않게** 한다 — 로보락·에코백스는 방해 금지 모드에서 도크에 돌아와도 먼지를 비우지 않는다. LG는 ThinQ 앱의 **야간 자동 먼지 비움 금지**
2. **비우는 횟수**를 줄인다 — 드리미 앱은 «낮은 빈도»를 고르면 **3번 청소한 뒤** 먼지를 비운다
3. 로보락 Qrevo 2 Pro 는 앱에서 **자동 비우기를 끌 수 있다**. 끈 동안은 먼지통을 손으로 비우거나 깨어 있는 시간에 앱에서 비운다
{{< /check >}}

![도크가 먼지를 비울 때 소리가 가장 크니, 방해 금지 시간에는 비우지 않게 하고 비우는 횟수를 줄이는 그림](/images/art_floornoise_empty.svg)

## 5. 소리가 커졌다면 — 손질부터

삼성전자서비스는 처음보다 소리가 커졌다면 **먼지통·필터에 먼지가 쌓였거나 브러시·바퀴에 머리카락이나 실이 끼었을 수 있다**고 안내합니다.

{{< check title="소리가 커졌을 때 손질 (삼성전자서비스 · LG · 에코백스)" >}}
1. 손질 전에 본체 바닥의 **비상 스위치를 끈다**(삼성)
2. **먼지통을 비우고 필터를 손질**한다 — 먼지통이 가득 차면 소음이 커질 수 있다(LG·삼성)
3. **메인 브러시와 사이드 브러시**에 감긴 머리카락·실을 없앤다 — 감기면 돌면서 마찰 소음이 날 수 있다(삼성·에코백스)
4. **바퀴와 앞바퀴**에 낀 머리카락을 끝이 날카롭지 않은 가는 막대나 집게로 뺀다 — 끼면 소리가 나거나 한쪽으로 휠 수 있다(삼성)
5. 강화 마루에서 **이동 방향에 따라** 소리가 나면 충전대 방향을 **90도 틀어** 다시 둔다(LG 코드제로 R5)
{{< /check >}}

소리 종류별로 더 자세한 순서는 [로봇청소기 소음 커짐 원인](/posts/로봇청소기-소음-커짐-원인-5가지-갑자기-시끄러워진-이유-2026/)에 정리했습니다. 로봇이 가구에 자주 부딪힌다면 바닥 정리와 금지 구역이 도움이 됩니다 — [로봇청소기 맵핑 초기설정](/posts/로봇청소기-맵핑-초기설정-완벽가이드-첫-실행부터-구역설정까지-2026/)의 금지 구역 부분을 보세요.

## 이웃과 문제가 생겼다면

{{< callout kind="note" title="층간소음 이웃사이센터 (한국환경공단)" >}}
- **전화상담**: 1661-2642(전국), 평일 09~18시(12~13시 제외)
- **방문상담**: 층간소음 이웃사이센터 누리집 → 층간소음 상담신청 → 상담신청 등록, 또는 콜센터
- 순서는 **전화상담 → 방문상담 → 소음측정**이고, 소음측정은 방문상담 뒤에도 갈등이 이어지면 소음을 듣는 쪽 세대가 신청한다
{{< /callout >}}

## 왜 이렇게 고쳤나

이 글의 9월 판은 실사용 후기를 AI로 요약해 만든 글이었습니다. 2026-11-26 에 법령 원문과 제조사 공식 안내와 하나씩 대조해 다시 썼습니다.

- **틀린 시간을 고쳤습니다.** 9월 판은 «환경부 층간소음 관리 가이드라인에 따르면 오후 10시~익일 오전 8시는 생활소음 규제 시간»이라고 적었습니다. 그런 문구를 법령정보센터와 이웃사이센터에서 찾지 못했고, 층간소음 규칙의 야간은 **22:00~06:00**입니다. «22:00~08:00»은 로보락·드리미 **방해 금지 모드의 기본 시간**과 같습니다. 이 둘이 섞인 것으로 보입니다.
- **근거 없는 숫자를 모두 뺐습니다.** «강력 모드 65~70dB, 표준 모드 50~55dB», «진동 저감 패드로 진동 전달 30~40% 감소», «55dB 이하 제품»은 공식 자료에서 확인할 수 없어 지웠습니다. 시간대별 별점 표와 따옴표로 넣었던 «후기» 문장도 뺐습니다.
- **관리 주기를 뺐습니다.** «주 1회 브러시 분리», «분기별 바퀴 청소»는 근거를 찾지 못했습니다. 손질 방법은 삼성·LG·에코백스 공식 안내로 바꿨습니다.
- **공식 자료에 있는 내용을 새로 넣었습니다.** 층간소음 기준표와 2023년 개정, 청소기 소음이 층간소음 범위에서 어떻게 다뤄지는지, 브랜드별 방해 금지 모드에서 멈추는 것(드리미는 예약 청소를 그대로 함), 흡입력 단계와 카펫 자동 터보 끄기, 음소거 방법, 먼지 비움을 밤에 막는 설정, 이웃사이센터 상담 순서입니다.
- **추천 제품을 뺐습니다.** 글 위의 «바쁘시면 이것부터» 상자와 아래 «이 글과 관련된 제품» 칸은 특정 제품이 층간소음에 낫다는 근거 없이 넣은 것이라 지웠습니다.
