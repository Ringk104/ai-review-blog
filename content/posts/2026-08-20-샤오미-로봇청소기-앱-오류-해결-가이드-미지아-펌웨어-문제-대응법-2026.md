## 1. 앱에서 기기를 못 찾거나, 추가가 안 될 때

{{< check title="기기가 앱에 연결되지 않을 때 (샤오미 고객지원)" >}}
1. 앱과 휴대폰 운영체제를 **최신 버전**으로 업데이트
2. **2.4GHz 와이파이**에 연결 — 샤오미 스마트 기기는 대부분 5GHz를 지원하지 않는다. 공유기가 두 대역을 한 이름으로 묶어 쓰면 대역을 나누거나 2.4GHz로 연결
3. 와이파이 이름·비밀번호에 **특수문자나 한자**가 없는지 · 기기를 공유기 가까이 옮기고, 공유기의 **차단 목록(블랙리스트)·MAC 주소 필터**는 잠시 끄기
4. 휴대폰 **블루투스**와 **위치 서비스** 켜기 — 일부 기기는 위치 서비스가 켜져 있어야 찾을 수 있다
5. 앱 권한 확인 — **위치, 저장공간, 백그라운드 실행**
6. 앱 설정의 **지역**이 기기를 산 지역과 같은지
7. 공유기와 로봇을 껐다가 다시 켜기
8. **다른 휴대폰의 핫스팟**에 연결해 보기 → 되면 집 와이파이 설정 문제
9. 같은 샤오미 계정으로 **다른 휴대폰**에서 연결해 보기 → 되면 내 휴대폰 문제
10. 그래도 안 되면 설명서대로 기기를 초기화한 뒤 처음부터 다시 연결
{{< /check >}}

![앱의 지역 설정이 기기를 산 지역과 같아야 한다 — 다르면 기기가 기기 추가 목록에 안 보일 수 있다](/images/art_xiaomi_region_match.svg)

{{< callout kind="key" title="지역 설정 — «한국»이 아니라 «산 곳»에 맞춥니다" >}}
샤오미 고객지원은 기기를 찾지 못하는 이유로 **그 기기가 지금 지역에서 판매되지 않는 경우**를 들고, 앱의 **프로필 → 설정 → 지역**을 **기기를 산 지역과 같게** 맞추라고 안내합니다. 지역이 맞지 않으면 일부 기기는 추가 자체가 막힐 수 있다고도 적습니다. 해외에서 산 제품이라면 산 지역부터 확인하세요.
{{< /callout >}}

기기를 찾지 못하는 다른 이유로 샤오미는 **신호가 약한 경우**와 **다른 사람이 이미 그 기기를 추가한 경우**를 듭니다. 이때는 기기를 초기화하고, 휴대폰 블루투스를 켠 채로 다시 추가합니다.

모델별 FAQ에는 이런 내용이 더 있습니다.

- **X20+** — 2.4GHz에서만 앱에 연결되고, 와이파이 이름·비밀번호가 바뀌었다면 와이파이를 재설정합니다. 공유기에 스마트 기기가 너무 많이 붙어 느려졌다면 공유기를 재시작합니다. 회사의 **EAP802.1x 인증 네트워크**나 웹 페이지 로그인이 필요한 **공용 와이파이**는 지원하지 않습니다.
- **5 Pro** — 로봇이 «연결 대기» 음성 안내를 내거나 표시등이 연결 대기 상태인지, **휴대폰과 기기가 같은 와이파이**에 있는지 확인하라고 합니다.

## 2. 앱에 «오프라인»으로 뜰 때

{{< check title="로봇이 오프라인일 때 (샤오미 고객지원)" >}}
1. 로봇이 **꺼져 있지 않은지** — 꺼져 있으면 전원 버튼을 길게 눌러 켠다
2. 로봇 자리의 **와이파이 신호가 약하거나 불안정한지** — 로봇과 가장 가까운 공유기로 네트워크를 다시 설정
3. 집 와이파이가 제대로 되는지 — 휴대폰으로 웹 페이지를 열어 보거나 다른 와이파이로 바꿔 시험
4. 1시간 넘게 오프라인이었다면 **로봇을 다시 시작** (X20+ FAQ)
{{< /check >}}

- 청소 중에 연결이 끊겨도 로봇은 **청소를 계속하고**, 신호가 돌아오면 **스스로 다시 연결**됩니다. 청소 도중 잠깐 오프라인이 뜬 것은 고장이 아닐 수 있습니다.
- X20+ FAQ에 따르면 기기가 **1시간 넘게 오프라인**이면 와이파이 모듈이 연결 기능을 닫고 와이파이 표시등이 깜박입니다. 이때는 로봇을 다시 시작해야 연결이 돌아옵니다.
- X20+ FAQ는 공유기와 로봇이 너무 멀면 로봇을 공유기 가까이(1~2m) 옮겨 다시 연결해 보라고 적습니다.
- 앱에서 **데이터를 불러오지 못하면** 네트워크를 확인하고 앱을 껐다가 다시 엽니다(X20+ FAQ).

## 3. 공유기를 바꿨거나, 계속 안 될 때 — 와이파이 재설정

공유기를 바꾸거나 와이파이 비밀번호를 바꾸면 로봇은 예전 네트워크를 찾느라 연결되지 않습니다. 이때는 로봇의 **와이파이를 재설정**한 뒤 앱의 **«+»**에서 기기를 다시 추가합니다.

{{< check title="가벼운 것부터 — X20+ 한국 FAQ 기준" >}}
1. **다시 시작** — 전원 버튼을 **15초** 눌러 강제로 끈 뒤, 전원 버튼을 **3초** 눌러 다시 켠다
2. **와이파이 재설정** — 윗덮개를 열고 **홈 버튼과 재설정 버튼**을 **5~7초** 눌러 «연결 대기» 음성 안내가 나오면 손을 뗀다 → 와이파이 표시등이 다시 깜박이면 성공 → 앱의 «+»로 다시 추가
3. **공장 초기화** — 덮개를 열고 도구로 **재설정 버튼**을 «기기 재설정 성공» 음성 안내가 나올 때까지 누른다. 설정이 모두 지워지니 마지막에
{{< /check >}}

{{< callout kind="warn" title="버튼 조합은 모델마다 다릅니다" >}}
위 버튼 조작은 **X20+** 기준입니다. 같은 와이파이 재설정이 **5 Pro**에서는 **전원 버튼과 충전(복귀) 버튼을 함께 7초** 눌러 «네트워크 설정 대기» 음성 안내가 나오게 하는 방식입니다. 내 모델명으로 샤오미 고객지원 FAQ나 사용설명서를 먼저 확인하세요.
{{< /callout >}}

## 4. 펌웨어 업데이트가 실패할 때

![펌웨어 업데이트는 로봇이 스테이션 위에 있고 배터리가 15% 이상일 때 — 네트워크도 확인](/images/art_xiaomi_firmware_station.svg)

{{< check title="펌웨어 업데이트 조건 (X20+ 한국 FAQ)" >}}
1. 로봇이 **스테이션(충전대) 위에** 있는지
2. 배터리가 **15% 이상**인지
3. **네트워크**가 제대로 되는지 — 위 2번 절의 오프라인 점검
4. 업데이트는 앱의 기기 화면 **설정 → 일반 설정 → 펌웨어 업데이트**에서
{{< /check >}}

- X20+는 펌웨어를 업데이트하는 동안 **모든 버튼이 깜박이고**, 로봇 표시등은 **흰색으로 깜박입니다**. 이때는 로봇을 건드리지 말고 기다립니다.
- 샤오미는 새 펌웨어에 보통 개선 사항이 들어 있으니 **나오면 바로 업데이트**하라고 권합니다. 5 Pro FAQ는 최신 기기와 맞도록 **앱도 최신 버전**으로 두라고 안내합니다.
- 조건을 맞췄는데도 계속 실패하면 3번 절의 **다시 시작**부터 해 보고, 안 되면 샤오미 서비스센터에 문의합니다.

## 5. 지도가 저장되지 않거나 틀어질 때

![청소 도중 로봇을 손으로 옮기거나 손으로 스테이션에 올리면 임시 지도만 생긴다](/images/art_xiaomi_temp_map.svg)

{{< check title="지도를 제대로 저장하려면 (X20+ 한국 FAQ)" >}}
1. 청소할 방의 **문을 모두 열어** 둔다
2. **빠른 지도 만들기**(청소 없이 집만 둘러봄, 약 5~15분) 또는 **집 전체 청소**를 스테이션에서 시작한다
3. 끝날 때까지 **로봇을 손으로 옮기지 않는다** — 스스로 스테이션에 돌아가야 지도가 완성된다
{{< /check >}}

- **지도가 안 남는 가장 흔한 이유** — X20+ FAQ에 따르면 로봇을 **손으로 스테이션에 올리거나** 청소 중에 **손으로 옮기면 임시 지도만** 생깁니다. 임시 지도에는 방 나누기가 없고, 구역 선택·방 이름 바꾸기 같은 기능을 쓸 수 없습니다.
- X20+는 지도를 **최대 3개**까지 저장합니다. FAQ에는 3개가 찼을 때 어떻게 되는지까지는 나와 있지 않습니다. 이미 3개인데 새 지도가 남지 않는다면, 지도 관리에서 안 쓰는 지도를 하나 지우고 다시 만들어 보세요.
- **지도가 기울거나 겹칠 때** — 거울 반사 같은 이유로 지도가 틀어질 수 있습니다. 지도 관리에서 **이전 버전으로 되돌리면** 다음 청소 때 다시 그립니다. 위쪽 **레이저 센서(LDS)** 주변 먼지를 깨끗한 천으로 닦고, 그래도 안 되면 로봇을 다시 시작하거나 재설정합니다.
- **방 하나를 다 하기 전에 다른 방으로 넘어가면** 앱에서 방 나누기가 잘못됐는지 보고 고칩니다.
- 이사나 가구 배치로 집 구조가 바뀌었다면 지도를 지우고 새로 만듭니다. 순서는 [로봇청소기 맵 초기화 방법](/posts/로봇청소기-맵-초기화-방법-지도-재생성-완벽-가이드-2026/)에 정리했습니다.

## 6. 스테이션으로 못 돌아갈 때

{{< check title="스테이션 복귀 실패 (X20+ 한국 FAQ)" >}}
1. 스테이션을 **트인 곳**에 두고 **양옆 5cm, 앞 1.5m** 안에 장애물이 없게
2. 청소를 **스테이션에서 시작**했는지 — 다른 곳에서 시작하면 청소 중 스테이션을 못 찾을 수 있다
