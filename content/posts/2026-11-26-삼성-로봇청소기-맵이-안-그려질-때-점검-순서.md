> 이 글은 삼성전자서비스 공식 안내(맵 삭제 후 재설정·영역 선택 청소·충전복귀·골고루 청소 안 될 때·라이다 센서 장애·리셋과 공장 초기화), 삼성 미국 고객지원의 제트봇 맵 FAQ, 삼성 멤버스 커뮤니티의 삼성전자 생활가전 담당자 안내를 바탕으로 AI가 정리하고 운영자가 확인했습니다. 모델마다 메뉴 이름이 다를 수 있으니 내 모델 설명서도 함께 확인하세요.

2. 맵에 넣을 방은 **문을 열고 불을 켠다** — 턱이 높은 방문은 닫는다
3. 침대·소파 사이처럼 **폭 50cm보다 좁은 곳**은 로봇이 못 들어간다
4. 로봇 앞쪽 **센서 창**을 부드러운 천으로 닦고 맵을 다시 그린다

삼성 로봇청소기는 스마트싱스(SmartThings) 앱의 **«공간학습»**으로 맵을 그립니다. 맵이 안 그려지거나 이상하게 그려질 때 삼성 안내가 먼저 보는 것은 고장이 아니라 **맵을 그릴 때의 조건**, 그리고 **충전기 위치와 주변 환경**입니다. 처음 맵을 그리는 순서는 [삼성 로봇청소기 맵 그리기 가이드](/posts/삼성-로봇청소기-맵-그리기-완벽-가이드-비스포크-제트봇-맵핑-설정법-2026/)에 있으니, 이 글은 **그렸는데 잘 안 된 경우**를 다룹니다.

![맵이 안 그려질 때 점검 순서 — 1 충전기에서 시작·완전 충전, 2 문 열고 불 켜기, 3 폭 50cm보다 좁은 곳, 4 센서 창 닦기, 5 센서 오류는 전원 껐다 켜기, 6 그래도 안 되면 초기화·서비스 점검](/images/flow_samsung_map_fail.svg)

## 먼저 알아 둘 것: 맵은 이렇게 만들어진다

- **충전기에서 시작해 끝까지 마쳐야** 맵이 만들어집니다. 삼성전자서비스는 맵 생성은 **반드시 충전기에서 시작해 정상적으로 완료되어야** 한다고 적습니다(영역 선택 청소 안내).
- 공간학습은 청소를 하지 않고 **먼저 돌아다니며 맵을 그립니다.** 로봇이 «청소전 먼저 자율주행하며 맵을 그릴께요» → «현재 위치를 확인 합니다» → «맵 그리기를 마무리합니다» 하고 안내한 뒤 충전기로 돌아가고, 앱에 맵이 표시됩니다.
- 맵은 **청소할 때마다 새로 그려지지 않습니다.** 삼성 미국 고객지원 FAQ는 맵을 다시 만들려면 **기존 맵을 지워야** 한다고 적습니다. 맵이 이상하면 «맵 관리 → 맵 삭제 → 공간학습»으로 다시 그립니다.

## 1단계: 공간학습이 일찍 끝나거나 일부만 그려질 때

![맵을 그리기 전에 맵에 넣을 방의 문을 열고 불을 켜 두고, 턱이 높은 방문은 닫아 둔다](/images/art_samsung_map_light_door.svg)

{{< check title="맵 그리기 전 준비 (삼성전자서비스)" >}}
1. 사용 전에 **배터리를 완전히 충전**해 둔다
2. 로봇을 **충전기에 올린 상태에서** 공간학습을 시작한다
3. 맵에 넣을 곳이나 이동 경로에 있는 **장애물을 치운다** — 식탁 의자, 바닥의 전선, 빨래 건조대
4. **턱이 높은 문은 가급적 닫는다**
5. 맵에 넣을 곳은 **어둡지 않게 조명을 켠다**
6. 충전기는 **좁은 통로나 방문 근처를 피하고**, 좌우 0.5m·앞 1m 이상 비운다 — 충전기 신호 때문에 일부 공간에 들어가지 못할 수 있다
{{< /check >}}

### 폭 50cm보다 좁은 곳은 못 들어간다

침대 옆이나 가구 사이 통로가 맵에서 빠졌다면 **폭**을 재 보세요. 삼성전자 생활가전 담당자는 삼성 멤버스 커뮤니티 답변에서 **제트봇이 들어갈 수 있는 최소 폭은 50cm**이고, 이보다 좁으면 들어가지 못하니 가구를 옮겨 폭을 넓히라고 안내했습니다.

![침대와 옷장 사이가 50cm보다 좁으면 로봇이 들어가지 못해 맵에서 빠지고, 50cm 이상 벌리면 들어간다는 비교 그림](/images/art_samsung_map_narrow.svg)

## 2단계: 특정 곳이 계속 빠질 때

- **반사되는 표면이나 그때 있던 물건**: 삼성 미국 고객지원 FAQ는 로봇이 어떤 곳을 계속 빠뜨린다면 **반사되는 표면**이나 **맵을 그릴 때 그 자리에 있던 물건** 때문일 수 있다고 적습니다. 물건을 치우고 맵을 다시 그려 보세요. 어둡고 물건이 많은 방은 **조명을 밝히고 장애물을 치우면** 나아진다고도 적혀 있습니다.
- **센서 창의 얼룩**: 삼성전자 생활가전 담당자 안내(제트봇)는 장애물이 없는데도 특정 공간을 피하거나, 한자리를 맴돌거나, 1cm보다 큰 장애물을 밀고 다니면 **범퍼 쪽 센서 창**을 보라고 합니다. 이물질이 묻거나 긁히면 앞을 제대로 보지 못하기 때문입니다.

![로봇 앞쪽 범퍼의 작은 센서 창을 안경 닦는 천처럼 부드러운 천으로 닦는 그림](/images/art_samsung_sensor_wipe.svg)

{{< check title="센서 창 닦고 맵 다시 (삼성전자 생활가전 담당자 안내)" >}}
1. 범퍼의 작은 센서 창을 **안경 닦는 천** 같은 부드러운 천으로 닦는다
2. 스마트싱스 앱 → 맵 관리 → **맵 삭제**
3. **공간학습** 또는 **청소하며 맵 그리기**로 맵을 다시 만든다
{{< /check >}}

빠진 곳이 맵에는 있는데 청소만 안 된다면 원인이 다를 수 있습니다. [로봇청소기가 특정 구역을 안 갈 때](/posts/로봇청소기-특정-구역-안감-해결법-매핑-오류-완벽-가이드-2026/)를 함께 보세요.

## 3단계: 맵이 있는데 처음부터 다시 그리며 청소할 때

저장된 맵이 있는데도 로봇이 청소를 시작하면서 **맵을 처음부터 다시 그리듯 움직인다면**, 로봇이 저장된 맵에서 **현재 위치를 찾지 못한 것**일 수 있습니다. 삼성전자 생활가전 담당자 안내는 제트봇이 저장된 맵과 청소 제외구역을 쓰려면 **맵을 그릴 때의 충전기 위치에서 시작해 위치인식에 성공해야** 한다고 설명합니다.

![맵을 그린 자리의 충전기에서 출발하면 저장된 맵에서 위치를 찾고, 충전기를 옮기거나 다른 곳에서 출발하면 위치를 못 찾는다는 비교 그림](/images/art_samsung_map_start_dock.svg)

{{< check title="위치를 못 찾는 원인 (삼성전자 생활가전 담당자 안내)" >}}
1. 맵을 그린 뒤 **청정스테이션을 옮겼다** → 원래 자리로 되돌리거나, 새 자리에서 맵을 다시 만든다. 삼성전자서비스는 **45도 이상 돌리거나 1m 이상 옮기면** 맵을 다시 만들라고 안내한다
2. 청정스테이션 **주변의 가구·방문·장애물**이 맵을 그릴 때와 달라졌다
3. 청정스테이션이 아닌 곳에서 **청소를 시작했다** — 충전기를 옮기지 않았어도 위치를 못 찾을 수 있다
4. 청정스테이션 **전원 코드가 콘센트에서 빠졌다**
{{< /check >}}

삼성전자서비스의 영역 선택 청소 안내도 같은 말을 합니다. 영역 청소가 제대로 안 되면 **충전기 위치, 장애물 배치, 문이 열려 있는지**가 맵을 만들 때와 같은지 확인하고, 그래도 반복해서 실패하면 **다른 맵을 고르거나 새 맵을 만들라**고 적습니다.

{{< callout kind="note" title="충전기 자리를 다시 정해야 한다면" >}}
삼성전자 생활가전 담당자 안내는 충전기를 **좌우 50cm, 앞 1m 안에 장애물이 없고 로봇이 주변을 넓게 볼 수 있는 곳**에 두라고 합니다. 자리를 정한 뒤 맵을 새로 만들고, 그 뒤로는 옮기지 않는 것이 좋습니다. 충전기로 잘 돌아오지 못하는 문제가 함께 있다면 [삼성 로봇청소기 충전복귀가 안 될 때](/posts/삼성-로봇청소기-충전복귀-안-될-때-점검-순서/)를 보세요.
{{< /callout >}}

## 4단계: 센서 오류 알림이 뜰 때

{{< check title="라이다 센서 장애 알림 (삼성전자서비스)" >}}
1. 일시적인 센서 오류일 수 있다
2. 로봇 **전원 버튼으로 전원을 껐다가(OFF) 다시 켠다(ON)**
3. 스마트싱스 앱에서 **[오류 해결]**을 누른 뒤 다시 쓴다
{{< /check >}}

**제트봇 AI**(모델명 VR50*95****)는 3D 센서를 스스로 보정하는 기능이 있습니다. 삼성전자 생활가전 담당자 안내는 3D 센서 이상 오류가 나면 스마트싱스 앱 → 설정 → **[3D 센서 보정]**을 실행하라고 합니다. 보정 전에는 청정스테이션을 **평평한 마룻바닥**에 두고, 앞과 좌우에 **50cm 정도 공간**을 두고, **반경 50cm 안의 카펫·러그와 장애물**을 치운 뒤 가까이 가지 않습니다.

## 5단계: 리셋, 공장 초기화, 서비스 점검

맵을 지우고 다시 그려도 같은 문제가 계속되면 다음 순서로 해 봅니다(제트 봇 콤보·AI 스팀·2026 비스포크 AI 스팀 기준).

{{< check title="리셋과 공장 초기화 (삼성전자서비스)" >}}
1. **리셋**: 상부 덮개를 열고, 작은 리셋 구멍을 클립처럼 끝이 가는 도구로 **«딸깍» 소리가 날 때까지** 누른다 — 제품을 다시 시작하는 방법이다
2. **공장 초기화**: 리셋 버튼을 누른 뒤 **시작/정지 버튼과 충전 복귀 버튼을 함께 7초** 누른다 → 흰색으로 깜박인 뒤 초기화되고 자동으로 다시 켜진다(2026 비스포크 AI 스팀은 흰색 깜박임 뒤 보라색으로 깜박인다)
3. 초기화하면 스마트싱스 앱에서 기기가 **오프라인**이 된다 → 기존 기기를 앱에서 삭제하고 **다시 등록**한다
4. 다시 등록한 뒤 **공간학습**으로 맵을 새로 그린다
{{< /check >}}

{{< callout kind="stop" title="이럴 땐 서비스 점검을" >}}
센서 창을 닦고, 충전기 자리를 정리하고, 초기화한 뒤 맵을 다시 그려도 **충전기 주변만 돌고 맵 그리기를 끝내거나 같은 곳을 계속 빠뜨린다면** 센서 자체에 문제가 있을 수 있습니다. 삼성전자 생활가전 담당자 안내는 센서 창에 닦이지 않는 흠집이 났거나 다른 문제가 있을 수 있으니 서비스 점검을 받으라고 합니다(삼성전자서비스 고객센터 1588-3366, 홈페이지 출장 서비스 예약). 모델명, 어떤 오류 알림이 떴는지, 위 점검 중 어디까지 해 봤는지를 함께 알려 주면 빠릅니다.
{{< /callout >}}

스마트싱스 연결 자체가 안 되면 [로봇청소기 Wi-Fi 연결 안될 때 해결법](/posts/로봇청소기-wi-fi-연결-안될-때-해결법-완벽-가이드-2026/)을, 다른 브랜드의 맵 다시 만들기는 [로봇청소기 맵 초기화 방법](/posts/로봇청소기-맵-초기화-방법-지도-재생성-완벽-가이드-2026/)을 보세요.

## 다시 생기지 않게 하려면

- 청소는 되도록 **충전기에서 출발**시킨다
- 맵을 그린 뒤에는 **충전기를 옮기지 않는다** — 옮겼다면 맵을 다시 만든다
- 충전기 주변의 **가구·방문 상태**를 맵 그릴 때와 비슷하게 유지한다
- 범퍼의 **센서 창**을 가끔 부드러운 천으로 닦는다

## 왜 이렇게 썼나

- **삼성전자서비스 안내가 없는 내용은 출처를 따로 밝혔습니다.** 위치를 못 찾는 원인 네 가지, 최소 폭 50cm, 센서 창 닦기, 3D 센서 보정은 삼성전자서비스 홈페이지가 아니라 **삼성 멤버스 커뮤니티의 삼성전자 생활가전 담당자 글·답변**에 있는 내용입니다. 삼성이 직접 쓴 안내라 넣었지만, 서비스 홈페이지 안내와 구분해 적었습니다.
- **오래된 안내도 하나 있습니다.** «조명을 켜라·턱이 높은 문은 닫아라·충전기에서 시작해 끝까지 마쳐라»는 삼성전자서비스의 2022년 영역 선택 청소(Select N Go) 안내에 있습니다. 예전 모델과 앱(삼성 스마트홈) 기준이지만 지금 안내와 어긋나는 내용이 없어 썼습니다.
- **미국 안내의 숫자는 뺐습니다.** 삼성 미국 고객지원 FAQ에는 가구 밑으로 들어가는 높이 같은 숫자도 있지만, 국내 모델에 같은 값인지 확인하지 못해 «반사 표면·그때 있던 물건» 같은 원인만 옮겼습니다.
- **충전기 앞 거리가 두 가지로 보입니다.** 충전기 주변은 «좌우 0.5m·앞 1m»(삼성전자서비스)이고, 3D 센서 보정 때의 «50cm 정도»는 보정할 때만의 기준입니다.
