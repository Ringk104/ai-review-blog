> 이 글은 삼성전자서비스 공식 안내(스마트싱스 오프라인·리셋과 공장 초기화)와 로보락 공식 사용설명서(S7·Qrevo 2 Pro 영문판)를 바탕으로 AI가 정리하고 운영자가 확인했습니다. 2026-11-13 에 전면 다시 썼습니다 — 고친 이유는 아래 «왜 이렇게 썼나»에 있습니다.

{{< action title="앱에서 로봇이 «오프라인»이면, 이 순서로" >}}
1. 최근 **공유기를 바꾸거나 와이파이 비밀번호를 바꿨는지** 떠올린다 — 그렇다면 앱에서 로봇을 지우고 다시 등록하는 것이 정답
2. 로봇이 **와이파이 신호가 닿는 곳**에 있는지 본다 (도크 자리 포함)
3. 앱을 **최신 버전**으로 올리고, 로봇을 **다시 시작(리셋)**한다
4. 그래도 안 되면 로봇의 **와이파이를 재설정**하고 새 기기로 추가한다
{{< /action >}}

앱 문제는 크게 둘로 나뉩니다. **처음 등록(기기 추가)이 안 되는 경우**와, **잘 쓰다가 앱에서 연결이 끊기는 경우**입니다. 처음 등록이 안 되는 경우(2.4GHz, 등록 오류 코드 등)는 [로봇청소기 Wi-Fi 연결 안될 때 해결법](/posts/로봇청소기-wi-fi-연결-안될-때-해결법-완벽-가이드-2026/)에 따로 정리했습니다. 이 글은 **잘 쓰던 로봇이 앱에서 끊겼을 때**를 다룹니다.

## 1. 공유기나 비밀번호를 바꿨다면 — 지우고 다시 등록

가장 흔하고 확실한 원인입니다. 로봇은 처음 등록할 때의 와이파이 이름·비밀번호를 기억하고 있어서, **공유기를 바꾸거나 비밀번호를 바꾸면 스스로 다시 붙지 못합니다.**

{{< check title="삼성 스마트싱스 — 오프라인 기기 지우고 다시 연결 (삼성전자서비스)" >}}
1. 스마트싱스 앱에서 **오프라인으로 표시된 로봇청소기 카드를 3초간** 누른다
2. 뜨는 창에서 **삭제**
3. 새 공유기(또는 바뀐 비밀번호의 와이파이)로 로봇청소기를 **다시 등록**한다 — 등록 방법은 모델마다 다르니 내 모델 안내를 확인
{{< /check >}}

로보락 설명서도 **«공유기 설정이 바뀌었거나 비밀번호를 잊었거나 그 밖의 이유로 연결할 수 없으면, 와이파이를 재설정하고 로봇을 새 기기로 추가하라»**고 적습니다. 재설정 방법은 아래 4번에 있습니다.

## 2. 신호가 닿는 곳인지

- 로보락 설명서는 도크를 **와이파이가 잘 잡히는 곳**에 두라고 하고, 연결이 안 될 때 **신호가 약하면 로봇을 신호 좋은 곳으로 옮기라**고 적습니다.
- 로봇은 청소 중에는 집 안을 돌아다니지만, 쉬는 동안은 도크에 있습니다. 앱을 열었을 때 자주 끊긴다면 **도크 자리의 와이파이 신호**부터 봅니다.

## 3. 앱 업데이트와 로봇 다시 시작

- 로보락 설명서의 «와이파이 연결 비정상» 해결책은 **와이파이 재설정, 앱 최신 버전 받기, 다시 시도**입니다.
- 앱 화면과 메뉴는 업데이트로 바뀔 수 있습니다. 두 제조사 모두 «실제 화면은 앱 버전에 따라 다를 수 있다»고 적습니다.

{{< check title="로봇 «다시 시작»은 이렇게" >}}
1. **삼성 제트봇 콤보**: 상부 덮개를 열고, 리셋 구멍에 클립 같은 가는 도구를 넣어 '딸깍' 느낌이 들 때까지 누른다 — 제품을 다시 시작하는 것으로, 등록은 그대로다(삼성전자서비스)
2. **로보락 Qrevo 2 Pro**: 버튼을 눌러도 반응이 없거나 꺼지지 않으면 윗덮개를 열고 **Reset 버튼**을 누른다 — 단, 이것은 «시스템 재설정»이라 **예약 청소·와이파이 같은 설정이 공장 상태로** 돌아간다
3. 그 밖의 모델은 설명서의 «다시 시작»·«재설정» 항목을 먼저 확인한다 — 이름이 같아도 지워지는 범위가 다르다
{{< /check >}}

{{< callout kind="warn" title="«리셋»과 «공장 초기화»는 다릅니다" >}}
삼성전자서비스는 **리셋은 제품을 다시 시작하는 것**, **공장 초기화는 초기화 뒤 스마트싱스에 다시 등록해야 하는 것**이라고 구분합니다. 공장 초기화를 하면 앱에서 로봇이 오프라인으로 바뀌므로, 기기 카드를 길게 눌러 삭제한 뒤 다시 등록해야 합니다. 앱 연결 문제라면 리셋 → 와이파이 재설정 순서로 먼저 해 보고, 공장 초기화는 마지막에 합니다.
{{< /callout >}}

## 4. 와이파이 재설정 후 새 기기로 추가

{{< check title="로보락 와이파이 재설정 (S7·Qrevo 2 Pro 설명서)" >}}
1. 설명서에 표시된 **두 버튼을 함께 길게** 눌러 «Resetting WiFi» 음성 안내가 나오게 한다 (누르는 버튼은 모델마다 다름)
2. 표시등이 **천천히 깜박이면** 연결을 기다리는 상태
3. Roborock 앱에서 기존 로봇을 지우고, «+»로 **새 기기로 추가**
4. S7은 연결을 **1시간 넘게 기다리면 와이파이가 자동으로 꺼지니**, 재설정한 뒤 바로 등록한다
{{< /check >}}

삼성 제트봇의 등록 순서(충전 복귀 버튼 길게 누르기, [vacuum]_E3 네트워크 연결)와 등록 오류 코드(11-001, 15-100 등)는 [와이파이 글](/posts/로봇청소기-wi-fi-연결-안될-때-해결법-완벽-가이드-2026/)에 있습니다.

## 5. 펌웨어 업데이트는 도크에서

로보락 S7 설명서는 펌웨어를 **앱에서 업데이트**하고, 업데이트는 **로봇이 도크에 있고 배터리가 20% 이상일 때** 하라고 적습니다. 업데이트 중에는 전원 표시등이 **흰색으로 빠르게 깜박입니다.** 업데이트 도중에 로봇을 들어 옮기거나 전원을 끄지 않도록 합니다.

## 왜 이렇게 썼나

이 글의 7월 판은 리뷰를 AI로 요약해 만든 글이었습니다. 2026-11-13 에 제조사 자료와 대조해 다시 썼습니다.

- **확인되지 않은 오류 번호와 버튼 조합을 지웠습니다.** «로보락 Error 106», «홈·청소 버튼 동시 5초 리셋», «드리미 클라우드 동기화 토글», «샤오미 계정 2단계 인증 해제», «LG 시리얼 번호 수동 입력» 등은 제조사 자료에서 확인하지 못했습니다.
- **근거 없는 숫자를 뺐습니다.** «90% 이상 해결», «공유기 문제가 40%», «허브와 5m 이내», «도크와 공유기 10m», «기기 등록 10~20대 제한», «전원 버튼 5~10초» 같은 숫자는 근거가 없어 지웠습니다.
- **공유기 보안 설정 조언을 뺐습니다.** «WPA3를 WPA2로», «MAC 필터 허용 목록», «VPN·광고 차단 앱 끄기»는 이번에 본 제조사 자료에 없었습니다.
- **가장 확실한 원인을 맨 앞에 두었습니다.** 삼성전자서비스는 공유기 교체·비밀번호 변경 뒤 오프라인이 되는 경우를 따로 안내하고, 로보락 설명서도 같은 경우 새 기기로 추가하라고 적습니다.
- **와이파이 글과 나눴습니다.** 처음 등록이 안 되는 문제는 와이파이 글에서, 잘 쓰다 끊기는 문제는 이 글에서 다룹니다.
