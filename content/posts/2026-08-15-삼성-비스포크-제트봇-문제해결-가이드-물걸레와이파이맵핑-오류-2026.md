## 1. 본체 표시등으로 상태 보기

삼성전자서비스의 제트봇 안내에 있는 본체 LED 상태 표시등의 뜻입니다.

{{< check title="제트봇 본체 표시등 (삼성전자서비스)" >}}
- **빨간색, 이동 없이 깜박임** — 에러 발생
- **빨간색 켜짐, 움직이지 않음** — 배터리 부족으로 멈춘 상태. 청정스테이션에 직접 올려 충전한다
- **빨간색·주황색·노란색** — 충전 중(충전율에 따라 색이 다름), **초록색** — 충전 완료
- **파란색** — 모니터링, **보라색** — 소프트웨어 업데이트 중
{{< /check >}}

![제트봇 표시등 읽기 — 본체가 빨간색으로 이동 없이 깜박이면 에러, 빨간색으로 켜진 채 멈춰 있으면 배터리 부족이라 청정스테이션에 올려 충전, 청정스테이션이 빨간색으로 깜박이면 커버 열림이나 흡입모터 이상, 빨간색으로 켜져 있으면 먼지봉투 가득 참(삼성전자서비스)](/images/art_jetbot_led.svg)

에러로 멈췄다면 멈춘 자리부터 봅니다. 끼임·걸림·바퀴 들림 같은 원인과 조치는 [로봇청소기 멈춤 원인 체크리스트](/posts/로봇청소기-멈춤-원인-체크리스트-작동-중단-해결-가이드-2026/)에 정리했습니다.

**앱에 «라이다 센서 장애» 알림이 떴다면**, 삼성전자서비스는 일시적인 오류일 수 있다며 **전원 버튼으로 껐다가 다시 켠 뒤** 스마트싱스 앱에서 **[오류 해결]**을 선택하라고 안내합니다.

**본체에 C00~C09 점검 코드가 표시되는 모델**이라면, 삼성전자서비스 «로봇청소기 에러 코드별 조치 방법» 표를 따릅니다. 코드가 뜨면 음성 안내가 나오고, 브러시·바퀴·센서를 청소하기 전에는 **본체 바닥의 비상 스위치를 끄라**고 안내합니다.

{{< check title="점검 코드 (삼성 로봇청소기 공통 안내)" >}}
- **C00** 주행 중 끼임·걸림 — 비상 스위치를 끄고 다른 곳으로 옮긴다
- **C01** 파워브러시, **C02·C03** 왼쪽·오른쪽 구동바퀴, **C09** 측면 회전솔에 이물 — 걸린 이물을 뺀다
- **C05** 부딪침 감지센서 — 앞에 붙은 장애물을 치우거나 다른 곳으로 옮긴다
- **C06** 장애물 센서창, **C07** 추락방지 센서창 — 부드러운 천으로 닦는다
- **C08** 먼지통 — 필터를 조립한 먼지통을 «딸깍» 소리가 나게 끼운다
{{< /check >}}

점검 코드는 동작/정지 버튼을 누르거나 비상 스위치를 끄면 해제될 수 있습니다. 이 표는 삼성 로봇청소기 공통 안내이고, 페이지에도 **코드와 조치는 모델에 따라 다를 수 있다**고 적혀 있습니다. 내 제트봇에 어떤 코드가 쓰이는지는 사용설명서로 확인하세요.

## 2. 물걸레가 안 붙거나 두고 나올 때 (AI 스팀)

비스포크 AI 스팀은 청정스테이션에서 물걸레를 스스로 붙였다 뗍니다. 물걸레를 두고 나온다면 삼성전자서비스는 다음을 확인하라고 안내합니다.

{{< check title="물걸레를 두고 나올 때 (삼성전자서비스 · 비스포크 AI 스팀)" >}}
- 청정스테이션에 **정수통·오수통·세척판**이 모두 조립되어 있는지 — 빠졌으면 다시 조립한다
- **정수통에 물이 있는지, 오수통이 가득 차지 않았는지** — 급수나 배수에 문제가 있으면 물걸레 청소를 시작하지 않는다
- **물걸레를 끼운 채 로봇을 손으로 밀어 넣지 않았는지** — 물걸레가 밀려 자동 부착이 안 될 수 있다
- 청정스테이션이 **바닥이 고르고 평평한 곳**에 있는지 — 기울어 있으면 자동 부착이 안 될 수 있다
- 로봇 바닥의 **브러시 덮개 후크**가 제대로 걸렸는지 — 덮개가 들뜨면 물걸레와 간섭된다
- 카펫 청소 옵션을 쓴다면 **모가 긴 카펫은 피한다** — 카펫은 청정스테이션에서 물걸레를 떼어 놓은 뒤 청소한다
{{< /check >}}

자동 부착이 계속 안 되면 직접 붙일 수 있습니다.

1. 로봇을 **뒤집어** 바닥면이 위를 향하게 살며시 내려놓습니다.
2. 바닥면의 **육각 홈이 들어가 있다면**, 전면의 **시작/정지 버튼**을 눌러 홈이 밖으로 나오게 합니다.
3. 물걸레를 **회전판 가운데 홈에 맞춰** 붙입니다. 물걸레를 **접어서 잡으면** 가운데에 맞추기 쉽습니다.
4. 청정스테이션 **약 1m 앞**에 로봇을 두고 **충전복귀 버튼**을 눌러 돌아가게 합니다.

![물걸레 직접 붙이기 — 로봇을 뒤집어 육각 홈이 들어가 있으면 시작/정지 버튼으로 꺼내고, 물걸레를 회전판 가운데 홈에 맞춰 접어 잡고 붙인 뒤, 청정스테이션 약 1m 앞에서 충전복귀 버튼을 누른다(삼성전자서비스 · 비스포크 AI 스팀)](/images/art_jetbot_mop.svg)

2026 비스포크 AI 스팀 자동 급배수 모델(VR90F01SAG·VR80F01SDG·VR70F00SGG)의 안내도 같은 내용이며, 여기에 청정스테이션의 **세척판과 세척 필터**가 조립되어 있는지 확인하라는 항목이 있습니다.

## 3. 물걸레 세척이 안 될 때 (AI 스팀)

청정스테이션에서 물걸레 세척이 안 되면, 삼성전자서비스는 원인을 세 가지로 봅니다. **물걸레가 한쪽만 붙었거나 제대로 장착되지 않은 경우, 정수통 물이 부족한 경우, 오수통이 가득 찬 경우**입니다.

{{< check title="물걸레 세척이 안 될 때 (삼성전자서비스 · 비스포크 AI 스팀)" >}}
- 물걸레 2개와 **회전판 2개**를 빼서 세척한 뒤, 회전판을 다시 조립하고 물걸레를 **가운데 홈**에 맞춰 붙인다 — 두 물걸레가 겹치지 않게
- **정수통**에 깨끗한 물을 채우고 바르게 장착한다
- **오수통**을 비우고 씻은 뒤, 뚜껑 잠금 장치를 **«딸깍» 소리가 날 때까지** 눌러 잠근다 — 덜 잠기면 세척이 안 될 수 있다
- 오수통을 비울 때 **세척판**도 함께 청소한다
{{< /check >}}

**세척판에 물이 고이고 오수통으로 회수되지 않는다면**, 오수통 덮개의 **검정색 고무 실링**이 제대로 끼워지지 않아 밀폐가 안 된 것일 수 있습니다. 오수통을 빼서 실링을 분리했다가 정확한 위치에 다시 끼우고, 물걸레(또는 물걸레+먼지 흡입) 모드로 청소를 시작해 물고임이 사라지는지 봅니다. 그래도 고이면 점검을 받으라고 안내합니다.

## 4. 스마트싱스에 등록이 안 될 때

제트봇은 스마트싱스(SmartThings) 앱에 등록해 씁니다. 삼성전자서비스의 아이폰 등록 안내에 나온 확인 사항입니다.

{{< check title="등록 전에 확인 (삼성전자서비스)" >}}
- 공유기를 **2.4GHz**로 선택한다 — 2022년 제트 봇 안내는 **5GHz 는 지원하지 않는다**고 적고 있다
- 로봇청소기가 놓인 곳의 와이파이 신호가 **안테나 3칸 이상**인지 본다
- 휴대폰을 **등록에 쓸 공유기**에 연결해 둔다
- 내 모델이 스마트싱스를 **지원하는지** 모델명으로 확인한다
{{< /check >}}

등록은 앱 하단 **[기기]** → 오른쪽 위 **추가(+)** 에서 시작합니다. 스테이션 아래쪽 스마트싱스 로고 옆에 **QR 코드**가 있으면 스캔하고, 없으면 **삼성기기 추가 → 로봇청소기 → QR코드 없이 추가 → 기기가 보이지 않나요? → 삼성 제트 봇** 순서로 고릅니다. 중간에 앱이 시키면 로봇의 **충전복귀 버튼을 신호음이 들릴 때까지 3초 이상** 누릅니다.

아이폰에서 기기 검색 방식으로 등록할 때는 휴대폰 **설정 → Wi-Fi** 에서 **[vacuum] 문구가 들어간 네트워크**를 고르고, 제품 연결용 암호 **1111122222**(1 다섯 번, 2 다섯 번)를 넣은 뒤 앱으로 돌아갑니다. 이 암호는 집 공유기 비밀번호가 아닙니다. 그다음 사용 장소의 2.4GHz 공유기를 고르고 **공유기 비밀번호**를 넣습니다.

![스마트싱스 등록 — 공유기는 2.4GHz 로(5GHz 미지원), 앱이 시키면 충전복귀 버튼을 신호음이 들릴 때까지 3초 이상, 아이폰 기기 검색 방식은 Wi-Fi 설정에서 vacuum 네트워크를 고르고 제품 암호 1111122222 입력(삼성전자서비스)](/images/art_jetbot_wifi.svg)

공유기 대역 확인, 휴대폰 설정 같은 일반적인 와이파이 점검은 [로봇청소기 Wi-Fi 연결 안될 때 해결법](/posts/로봇청소기-wi-fi-연결-안될-때-해결법-완벽-가이드-2026/)에 정리했습니다. 위 순서대로 해도 등록이 안 되면 삼성전자서비스는 전화상담 예약을 이용하라고 안내합니다.

## 5. 맵이 안 맞을 때 — 맵 삭제 후 다시 만들기

삼성전자서비스는 **청정스테이션을 설치한 뒤 45도 회전하거나 1m 이상 옮겨 다시 설치했다면** 스마트싱스 앱에서 맵을 다시 만들라고 안내합니다. 기존 맵을 그대로 쓰면 **청소하지 않는 곳이 생길 수 있기** 때문입니다.

1. 스마트싱스 앱 하단 **[기기]** 에서 로봇청소기를 고릅니다.
2. 메뉴를 위로 올려 **[맵 관리]** 를 고릅니다.
3. **[맵 삭제]** 로 쓰던 맵을 지웁니다.
4. **[공간학습]** → **[시작]** 을 누르면 로봇이 스스로 돌아다니며 맵을 그립니다.
5. 맵이 나오면 **청소 제외구역**과 **가상벽**을 다시 설정합니다.

맵을 다시 만들어도 특정 방을 안 가거나 일부만 청소한다면 [로봇청소기 특정 구역 안감 해결법](/posts/로봇청소기-특정-구역-안감-해결법-매핑-오류-완벽-가이드-2026/)을 참고하세요.

## 6. 청정스테이션으로 못 돌아갈 때

삼성전자서비스의 제트봇 충전 안내에서 핵심만 추렸습니다.

{{< check title="충전 복귀가 안 될 때 (삼성전자서비스 · 제트봇)" >}}
- 청정스테이션은 **바닥과 벽이 평평한 곳**에 둔다
- 청정스테이션과 로봇의 거리가 **5m 이상**이면 복귀에 오래 걸릴 수 있다
- 설치 장소의 문턱을 못 넘으면 복귀하지 못한다 — 주행 가능 문턱 높이는 **약 1.5cm 이하**
- 구석에 설치했거나, 배터리가 완전히 방전됐거나, 가구 사이에 갇혔다면 **직접 올려 충전**한다
- 충전이 안 되면 플러그를 뺀 상태에서 **충전 단자를 마른 부드러운 천**으로 닦는다
{{< /check >}}

처음 쓰는 제트봇이 전혀 켜지지 않는다면, 본체 **측면 전원 스위치의 노란색 개스킷**을 빼고 전원 스위치를 켰는지도 봅니다. 충전기 주변 공간, 직접 복귀 시험 방법은 [삼성 로봇청소기 충전복귀가 안 될 때](/posts/삼성-로봇청소기-충전복귀-안-될-때-점검-순서/)에 자세히 정리했습니다.

## 7. 청정스테이션 표시등이 빨간색일 때

청정스테이션 표시등은 세대마다 뜻이 조금 다릅니다. 삼성전자서비스 안내 기준입니다.

{{< check title="청정스테이션 표시등 (삼성전자서비스)" >}}
- **제트봇 청정스테이션** — 빨간색 **깜박임**은 커버 열림·흡입모터 이상, 빨간색 **켜짐**은 먼지봉투 가득 참
- **AI 스팀 청정스테이션** — 빨간색 **깜박임**은 먼지봉투 쪽 덮개가 열렸거나 고성능 필터 손질 시기. 덮개를 정확히 닫고 필터를 빼서 털어 다시 끼운다
- **AI 스팀 청정스테이션** — 빨간색 **켜짐**은 먼지봉투 쪽 유로가 막혔거나 먼지봉투가 가득 참, 오수통이 가득 참, 정수통에 물이 없음, 정수통·오수통·세척판이 조립되지 않음
{{< /check >}}

비스포크 제트 봇(VR30T85513 계열)의 먼지봉투는 청정스테이션 윗면의 **PUSH 버튼**으로 뚜껑을 열고, 먼지봉투 홀더 위쪽을 살짝 당겨 봉투를 바꾼 뒤 홀더를 **«딸깍» 소리가 날 때까지** 밀어 고정합니다. 먼지 비움이 아예 안 될 때의 점검은 [로봇청소기 먼지비움 안됨 해결법](/posts/로봇청소기-먼지비움-안됨-해결법-클린베이스-점검-체크리스트-2026/)에 있습니다.

## 8. 구동 바퀴와 측면 회전솔 손질

비스포크 제트 봇 손질 안내입니다. 두 경우 모두 **손질 전에 옆면의 전원 스위치를 끕니다**.

{{< check title="바퀴·회전솔 손질 (삼성전자서비스 · 비스포크 제트 봇)" >}}
- **구동 바퀴** — 바닥에 부드러운 천을 깔고 로봇을 뒤집어 놓은 뒤, 막대나 집게로 바퀴에 낀 이물을 뺀다
- **측면 회전솔** — 스팀 타월 등으로 **약 10초** 감쌌다가 닦는다
- 회전솔과 본체 틈에 머리카락·실이 많이 감겼다면, 회전솔을 잡은 채 **(+) 드라이버**로 분리해 뺀다
- 회전솔이 많이 상했다면 **여분의 회전솔**로 바꾼다
{{< /check >}}

## 그래도 안 되면 — 서비스 점검

{{< callout kind="stop" title="위 조치를 해도 같은 증상이면" >}}
삼성전자서비스는 안내한 방법으로 해결되지 않으면 **출장서비스 예약**으로 전문 엔지니어의 방문 점검을 받으라고 안내합니다. 같은 점검 코드가 반복되거나, 충전 단자·스위치를 확인해도 충전이 안 되거나(배터리·충전 부품 이상 가능성), 오수통 실링을 다시 끼워도 세척판에 물이 고이는 경우가 여기에 해당합니다. 스마트싱스 등록 문제는 전화상담 예약을 이용합니다(대표전화 1588-3366).
{{< /callout >}}

접수할 때는 **모델명**, 표시등 색이나 앱 알림·점검 코드, 위 순서 중 **어디까지 해 봤는지**를 함께 알려 주면 상담이 빨라집니다. 삼성전자서비스 페이지마다 적혀 있듯, **무상 보증기간 안이라도 사용법 설명·설치처럼 고장이 아닌 경우**로 서비스를 부르면 요금이 붙습니다. 브랜드별 A/S 창구는 [로봇청소기 AS 비교](/posts/로봇청소기-as-비교-브랜드별-수리-비용서비스센터-가이드-2026/)에 정리했습니다.

## 왜 이렇게 고쳤나

이 글의 8월 판은 실구매자 리뷰를 AI로 요약해 만든 글이었습니다. 2026-11-23 에 삼성전자서비스 공식 안내와 하나씩 대조해 다시 썼습니다.

- **근거 없는 숫자와 주장을 뺐습니다.** «본체 전원 버튼을 10초간 길게 눌러 재시작», «재부팅·센서 청소·앱 재설치·맵 초기화로 90% 이상 해결», «패드는 3개월 안팎이면 교체 시점», «SSID 에 #·%·& 가 있으면 인식 안 됨», «2.4GHz 채널을 1·6·11번으로 고정하면 개선»은 삼성 공식 안내에서 확인하지 못해 지웠습니다. 따옴표로 넣었던 «후기» 인용문도 출처를 확인할 수 없어 뺐습니다.
- **물걸레 «인식 안 됨» 단계를 공식 안내로 바꿨습니다.** «패드 벨크로 점검», «물걸레 장착 부위 금속 접점을 면봉으로 닦기», «'딸칵' 소리가 날 때까지 끼우기», «순정 패드가 아니면 인식 안 됨»은 공식 자료에서 찾지 못했습니다. 대신 AI 스팀의 정수통·오수통·세척판 확인, 손으로 밀어 넣지 않기, 브러시 덮개 후크, 육각 홈과 시작/정지 버튼, 물걸레 직접 부착과 1m 앞 충전복귀를 넣었습니다.
- **맵 부분을 고쳤습니다.** «거울·창문이 LDS 센서 혼선», «커튼을 치고 거울을 천으로 가리기», «낮 시간대 자연광에서 맵핑», «설정 → 지도 관리 → 저장된 지도», «'지도 재설정' 후 '전체 청소'»는 삼성 안내에서 확인하지 못했습니다. 공식 메뉴 이름인 [맵 관리] → [맵 삭제] → [공간학습]과, 맵을 다시 만들 조건(45도 회전·1m 이동)으로 바꿨습니다.
- **와이파이 부분을 공식 등록 안내로 바꿨습니다.** «공유기 펌웨어 업데이트», «앱을 지우고 다시 설치하면 안정화», «두꺼운 벽·금속 가구가 신호 차단»은 제트봇 안내에서 찾지 못했습니다. 2.4GHz·안테나 3칸 이상·충전복귀 버튼 3초 이상·[vacuum] 네트워크와 제품 암호를 넣었습니다.
- **«보증 기간 내라면 무상 수리», «펌웨어 구버전은 알려진 버그»를 뺐습니다.** 이번에 읽은 공식 안내에는 그 내용이 없습니다. 오히려 고장이 아닌 경우는 보증기간 안이라도 요금이 붙는다는 안내를 넣었습니다.
- **부품 판매 블록과 링크를 뺐습니다.** 문제 해결과 상관없는 판매 링크와 «구매가이드» 태그를 지웠습니다.
- **공식 자료에 있는 내용을 새로 넣었습니다.** 제트봇 본체·청정스테이션 표시등 색, 라이다 센서 장애 알림, C00~C09 점검 코드, 물걸레 세척이 안 될 때와 오수통 실링, 충전 복귀(5m·1.5cm 문턱·노란색 개스킷), 먼지봉투 교체, 구동 바퀴·측면 회전솔 손질입니다.
