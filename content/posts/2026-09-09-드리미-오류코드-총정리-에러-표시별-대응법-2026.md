먼저 알아 둘 것이 있습니다. **드리미 로봇청소기는 «E01·E02» 같은 번호 코드로 오류를 알려 주지 않는 모델이 많습니다.** 이번에 본 드리미 설명서(L10s Pro Gen 2)에는 번호 오류표가 없고, 오류가 나면 상태 표시등이 **주황색으로 깜박이며**, 무엇이 문제인지는 앱 알림과 음성 안내로 알려 줍니다. 그래서 «번호»보다 **앱에 뜬 문장(증상)**으로 찾는 것이 정확합니다.

{{< callout kind="warn" title="«E01~E08» 표를 지운 이유" >}}
이 글의 9월 판은 «E01 메인 브러시 막힘, E03 LDS 센서 막힘, C01 Wi-Fi 끊김» 같은 번호표를 실었지만, 드리미 공식 자료에서 이 번호를 확인하지 못해 모두 지웠습니다. 드리미 고객지원의 E1·EE·EF 같은 번호 안내는 **무선·습식 청소기(H 시리즈)** 것이라 로봇청소기에 그대로 쓰면 안 됩니다. 내 모델 화면에 번호가 뜬다면 **내 모델 설명서의 표**를 보세요.
{{< /callout >}}

## 증상별 조치 — 드리미 설명서 문제 해결 표

| 증상 | 드리미 설명서의 조치 |
|---|---|
| 로봇이 켜지지 않음 | 배터리 부족 → 도크에서 충전 후 다시 · 배터리 온도가 너무 낮거나 높음 → **0~40℃**에서 사용 |
| 충전이 안 됨 | 도크에 전원이 안 들어감 → 전원선 양쪽 연결 확인 · 접촉 불량 → 도크와 로봇의 **충전 단자 청소** |
| 도크로 돌아가지 않음 | 도크 주변 장애물이 너무 많음 → 트인 곳으로 옮기기 · **도크 신호부 청소** |
| 손으로 옮긴 뒤 도크로 못 감 | 옮기면 위치를 다시 잡거나 지도를 다시 만듦 → 도크가 멀면 손으로 도크에 올려 두기 |
| 오작동 | 로봇을 **껐다가 다시 켜기** |
| 이상한 소리 | 메인 브러시·사이드브러시·바퀴에 이물질 → 멈추고 제거 |
| 청소가 덜 되거나 먼지를 남김 | 먼지통이 가득 참 → 비우기 · **필터 막힘** → 청소 · 메인 브러시에 이물질 → 청소 |
| 와이파이 연결 안 됨 | 와이파이 재설정 + 앱 최신 버전 · 앱 **위치 권한** 켜기 · 신호 좋은 곳 · **2.4GHz만 지원** · 와이파이 이름·비밀번호 확인 |
| 예약 청소를 안 함 | 배터리가 **15% 이상**이어야 예약 청소가 시작됨 |
| 물이 안 나오거나 적게 나옴 | 물통에 물 확인 · 걸레가 더러우면 빨기 · 걸레 바르게 장착 · **물통 마개의 공기 구멍** 청소 |
| 충전 뒤 이어서 청소하지 않음 | **방해 금지(DND)** 모드인지 확인 · 손으로 도크에 올린 경우는 이어서 하지 않음 |
| 걸레가 돌지 않음 | 걸레에 이물질이 걸림 → 청소 |
| 걸레 받침이 비정상적으로 들림 | 걸레 받침을 빼서 걸린 것을 확인하고 로봇 재시작 → 계속되면 고객지원 |

설명서 표는 모델마다 조금씩 다릅니다. 이 표는 L10s Pro Gen 2 기준이라, 스테이션형(올인원) 모델은 물통·오수통·세척 트레이 항목이 더 있을 수 있습니다.

## 앱에 자주 뜨는 알림과 볼 곳

드리미 고객지원의 수리 안내에는 로봇청소기 **오류 메시지 목록**이 있습니다. 라이다(LDS) 센서 경고, «필터를 확인하고 청소하세요», 절벽 센서 이상, 모서리 센서 오류, 메인 브러시 엉킴, 사이드브러시 오류(안 돎), 구동 바퀴에 이물질 감김, 바퀴 들림, 걸레에 이물질 감김, 본체 기울어짐, 범퍼(충돌 센서) 오류, 먼지통 미장착, 금지 구역·가상벽 안에 들어감, 내부 오류 등입니다. 알림 문장별로 볼 곳은 다음과 같습니다.

![로봇 바닥의 절벽 센서·메인 브러시·사이드브러시·바퀴 위치와 각각의 조치](/images/art_robot_underside.svg)

{{< check title="알림별 점검 (드리미 설명서 정기 관리 항목 기준)" >}}
1. **절벽 센서** 관련 → 로봇 바닥의 절벽 센서를 마른 천으로 닦는다
2. **메인 브러시** 엉킴 → 브러시를 빼서 감긴 머리카락·실을 제거한다
3. **필터** 확인 → 먼지통 필터를 꺼내 청소한다 (교체 뒤에는 앱의 소모품 기록도 확인)
4. **사이드브러시·바퀴·걸레** 감김 → 걸린 이물질을 제거한다
5. **라이다(LDS)·라인 레이저·모서리 센서·범퍼** → 표면을 닦는다
6. **바퀴 들림·기울어짐** → 평평한 바닥으로 옮겨 다시 시작한다
7. **금지 구역·가상벽 안** → 로봇을 그 구역 밖으로 옮긴다 (6·7번은 드리미 표에 조치가 없어, 같은 오류에 대한 로보락 S7 설명서의 조치를 옮겼습니다)
8. 위를 해도 같은 알림이 계속되면 로봇을 껐다 켜고, 그래도 계속되면 고객지원
{{< /check >}}

와이파이·네트워크 오류는 단계가 많아서 [드리미 네트워크 연결 오류 점검 순서](/posts/드리미-네트워크-연결-오류-점검-순서/)에 드리미 공식 안내 기준으로 따로 정리했습니다.

## 왜 이렇게 썼나

이 글의 9월 판은 리뷰를 AI로 요약해 만든 글이었습니다. 2026-11-13 에 드리미 공식 자료와 대조해 다시 썼습니다.

- **확인되지 않은 번호표를 지웠습니다.** «E01~E08, C01·C02, E·W·C 분류» 는 드리미 로봇청소기 공식 자료에서 확인하지 못했습니다. 번호가 아니라 앱 알림 문장으로 찾도록 바꿨습니다.
- **«숨겨진 진단 모드(전원+홈 5초)»를 지웠습니다.** 드리미 자료에 없는 조작이고, 비슷한 버튼 조합이 다른 기능(재설정 등)일 수 있어 위험합니다.
- **근거 없는 숫자를 뺐습니다.** «오류의 60%는 센서·브러시», «공유기 재부팅으로 80% 해결», «응대 시간 40% 단축», «30분 냉각», «필터 24시간 건조» 같은 숫자는 근거가 없었습니다. 남긴 숫자(0~40℃, 배터리 15%, 교체 주기)는 모두 드리미 설명서 값입니다.
- **관리 주기를 드리미 값으로 바꿨습니다.** 9월 판의 «주 1회 브러시, 월 1회 필터 세척, 분기마다 배터리 완전 방전»은 출처가 없었습니다. 특히 «완전 방전 후 완충»은 설명서에 없고, 설명서는 오히려 다 충전된 뒤 도크에 두는 것이 배터리 상태 유지에 좋다고 적습니다.
