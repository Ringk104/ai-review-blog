> 이 글은 로보락 공식 사용설명서(S7·Qrevo 2 Pro 영문판)와 삼성전자서비스 공식 안내(제트봇 스마트싱스 연결·청소기 기기 등록 오류)를 바탕으로 AI가 정리하고 운영자가 확인했습니다. 2026-11-11 에 전면 다시 썼습니다 — 고친 이유는 아래 «왜 이렇게 썼나»에 있습니다.

{{< action title="와이파이 연결이 안 되면, 이 순서로" >}}
1. 휴대폰이 **2.4GHz 와이파이**에 연결돼 있는지 본다 — 로봇청소기는 5GHz를 지원하지 않는 경우가 많다
2. 로봇(또는 도크)을 **와이파이 신호가 좋은 곳**으로 옮기고, 휴대폰도 로봇 가까이에 둔다
3. 로봇의 **와이파이를 재설정**하고, 앱에서 **새 기기로 다시 추가**한다
4. 앱을 **최신 버전**으로 올린 뒤 다시 해 본다
{{< /action >}}

로봇청소기 와이파이 문제는 대부분 **처음 연결(기기 등록)** 단계에서 막힙니다. 제조사 설명서가 공통으로 짚는 것은 세 가지입니다. **2.4GHz만 지원한다**, **신호가 약하면 옮긴다**, **안 되면 와이파이를 재설정하고 새 기기로 추가한다**.

## 1. 2.4GHz 와이파이인지 확인

- 로보락 S7과 Qrevo 2 Pro 설명서 모두 **«2.4GHz 와이파이만 지원»**이라고 적습니다. 무선 사양도 2400~2483.5MHz(802.11b/g/n)입니다.
- 삼성전자서비스의 제트봇 연결 안내도 **«2.4GHz 와이파이를 선택하세요. 5GHz 와이파이는 지원하지 않습니다»**로 시작합니다.

공유기가 2.4GHz와 5GHz를 **같은 이름**으로 내보내면 휴대폰이 어느 쪽에 붙었는지 알기 어렵습니다. 공유기 설정에서 두 대역의 이름을 나누면 2.4GHz를 고르기 쉽습니다. 설정 방법은 공유기마다 다르니 공유기 설명서를 보세요.

## 2. 신호가 닿는 곳인지 확인

- 로보락 설명서는 **도크를 와이파이가 잘 잡히는 곳**에 두라고 적고, 연결이 안 될 때 **«신호가 약하면 로봇을 신호 좋은 곳으로 옮기라»**고 안내합니다.
- 삼성전자서비스는 기기 등록 오류의 원인으로 **휴대폰의 와이파이 감도가 낮거나 전파 방해 요소가 있는 환경**을 듭니다. 휴대폰 와이파이 표시가 **3칸 이하**면 자리를 옮기고 주변에 전파를 막는 것이 없는지 보라고 합니다.

삼성 제트봇은 등록 중에 휴대폰을 로봇이 내보내는 네트워크(«Soft AP»)에 잠깐 연결합니다(아래 4번). 삼성전자서비스가 이때 휴대폰의 와이파이 감도를 확인하라고 하는 이유입니다. 삼성 안내도 오류가 나면 가까운 거리에서 다시 추가하라고 적습니다.

## 3. 와이파이 재설정 후 새 기기로 추가 — 로보락

로보락 설명서는 **공유기 설정이 바뀌었거나, 비밀번호를 잊었거나, 그 밖의 이유로 연결이 안 되면 와이파이를 재설정하고 로봇을 새 기기로 추가하라**고 적습니다. 공유기를 바꾼 경우도 같은 순서입니다.

{{< check title="로보락 와이파이 재설정 (S7·Qrevo 2 Pro 설명서)" >}}
1. 설명서에 표시된 **두 버튼을 함께 길게** 눌러 «Resetting WiFi» 음성 안내가 나오게 한다 (S7은 윗덮개를 열면 와이파이 표시등 옆에 있음 — 누르는 버튼은 모델마다 다르니 내 모델 설명서 확인)
2. 표시등이 **천천히 깜박이면** 재설정 완료 — 로봇이 연결을 기다리는 상태
3. Roborock 앱에서 «+» 또는 «기기 추가»를 눌러 앱 안내대로 등록
4. 앱 화면은 업데이트에 따라 바뀔 수 있으니 **앱의 안내를 따른다**
{{< /check >}}

표시등으로 지금 상태를 알 수 있습니다.

| 표시등 | 뜻 |
|---|---|
| 꺼짐 | 와이파이 꺼짐 (S7) |
| 천천히 깜박임 | 연결 기다리는 중 |
| 빠르게 깜박임 | 연결하는 중 |
| 켜져 있음 | 연결됨 (S7) |

S7은 와이파이 표시등이 따로 있고, Qrevo 2 Pro는 전원 표시등이 **흰색으로 천천히 깜박이면 연결 대기, 빠르게 깜박이면 연결 중**입니다.

{{< callout kind="warn" title="1시간 넘게 두면 와이파이가 꺼집니다" >}}
S7 설명서는 로봇이 **1시간 넘게 연결을 기다리면 와이파이가 자동으로 꺼진다**고 적습니다. 재설정해 놓고 한참 뒤에 앱에서 추가하려 하면 로봇이 보이지 않을 수 있으니, 그럴 때는 와이파이를 다시 재설정한 뒤 바로 등록합니다.
{{< /callout >}}

로보락 설명서의 «와이파이에 연결할 수 없음» 해결책은 다음과 같습니다.

- **와이파이가 꺼져 있음** → 와이파이를 재설정하고 다시 시도
- **신호가 약함** → 로봇을 신호 좋은 곳으로 옮기기
- **연결이 비정상** → 와이파이 재설정, **앱 최신 버전 받기**, 다시 시도
- **앱이 지원하지 않는 로봇** → 앱에서 지원 모델 확인 (S7 설명서)
- **잘 되다가 갑자기 연결이 안 됨** → 공유기 설정에 문제가 있을 수 있음 → 로보락 고객지원 문의

{{< callout kind="note" title="시스템 재설정과 헷갈리지 마세요" >}}
Qrevo 2 Pro 설명서의 «시스템 재설정»(덮개 안 Reset 버튼)은 버튼이 안 먹거나 전원이 꺼지지 않을 때 쓰는 것이고, 하고 나면 **예약 청소·와이파이 같은 설정이 공장 상태로** 돌아갑니다. 와이파이만 다시 잡을 때는 위의 «와이파이 재설정»을 씁니다. 또 Reset 버튼을 음성 안내가 나올 때까지 누르고 5분 기다리면 와이파이 연결이 꺼진다고 적혀 있습니다. 다시 연결하려면 위 연결 순서를 처음부터 합니다.
{{< /callout >}}

## 4. 삼성 제트봇 — 스마트싱스 연결과 등록 오류

삼성 로봇청소기는 **SmartThings(스마트싱스) 앱**으로 연결합니다. 삼성전자서비스의 제트봇 연결 안내(iOS 기준)는 다음 순서입니다.

{{< check title="제트봇 스마트싱스 연결 (삼성전자서비스, iOS 기준)" >}}
1. 휴대폰 설정 → Wi-Fi에서 **2.4GHz 와이파이**를 고른다
2. SmartThings 앱에서 «+» → 디바이스 → QR 코드 스캔(로봇 윗덮개를 열면 왼쪽에 QR 코드) 또는 로봇청소기 → 삼성 → 제트봇 선택
3. 앱 안내에 따라 **신호음이 들릴 때까지 로봇의 충전 복귀 버튼을 길게** 누른다
4. 휴대폰 Wi-Fi 설정에서 **[vacuum]_E3**으로 시작하는 네트워크에 연결한다 (암호는 안내 화면 기준)
5. SmartThings 앱으로 돌아가 **공유기 비밀번호**를 입력하고 완료
{{< /check >}}

연결하다가 오류 코드가 뜨면, 삼성전자서비스 청소기 안내는 다음과 같이 원인과 조치를 적습니다.

| 오류·증상 | 원인 (삼성 안내) | 조치 |
|---|---|---|
| 11-001 · 12-001, 진행률 44% 전에 멈춤 | 휴대폰의 와이파이 감도가 낮거나 전파 방해, 제품이 응답하지 않음 | 휴대폰 와이파이 감도 확인(3칸 이하면 이동) · 제품 전원 코드를 뺐다 꽂고(어려우면 전원 버튼 끄기→켜기) 앱 다시 실행 · 안드로이드는 «모바일 데이터로 전환» 끄고 다시 추가 |
| 15-100 · 15-200 · 15-300, 99%(98%)에서 멈춤 | 제품과 공유기 사이 연결 장애, 스마트싱스 서버 등록 실패 | 전원 코드를 뺐다가 **30초 뒤** 다시 꽂기 · **공유기 비밀번호가 맞는지** 확인 · 가까운 거리에서 다시 추가 |

안드로이드의 «모바일 데이터로 전환»은 설정 → 연결 → Wi-Fi → 더보기 → 고급에 있습니다(삼성 안내 기준, 휴대폰·앱 버전에 따라 화면이 다를 수 있음).

{{< callout kind="note" title="와이파이 초기화 버튼은 모델마다 다릅니다" >}}
삼성전자서비스의 오류 안내에는 청정스테이션 «Auto Empty» 버튼으로 와이파이를 초기화하는 방법이 나오는데, 이 버튼 위치와 누르는 시간은 제품마다 다릅니다. 이 글에는 옮기지 않았으니 **내 모델 설명서나 삼성전자서비스에서 모델명으로** 확인하세요.
{{< /callout >}}

## 왜 이렇게 썼나

이 글의 5월 판은 리뷰를 AI로 요약해 만든 글이었습니다. 2026-11-11 에 제조사 자료와 대조해 다시 썼습니다.

- **근거 없는 숫자를 뺐습니다.** «공유기 3m 이내», «직선거리 5m 이내», «90% 이상 해결 가능», «공유기 끄고 30초·켜고 2~3분» 같은 숫자는 확인할 수 있는 근거가 없어 지웠습니다. 남긴 숫자(«와이파이 표시 3칸 이하», «전원 코드 30초 뒤», «1시간 뒤 와이파이 꺼짐», «Reset 버튼 후 5분»)는 모두 제조사 안내에 있는 값이고 출처를 함께 적었습니다.
- **재설정 버튼 조합을 지웠습니다.** 5월 판의 «홈 버튼과 충전 버튼 동시 10초»는 특정 제조사 자료에서 확인되지 않았습니다. 버튼은 모델마다 다르므로 설명서를 보도록 바꿨습니다.
- **공유기 보안 설정 조언을 뺐습니다.** «WPA3를 WPA2로 바꾸기», «MAC 필터링 해제», «동시 접속 기기 수 제한»은 이번에 본 제조사 자료에 없어 뺐습니다. 공유기 설정이 의심되면 로보락 설명서대로 고객지원에 문의하는 것이 안전합니다.
- **«제조사 A 계열», «제조사 C» 같은 이름 없는 브랜드 설명을 뺐습니다.** 어떤 제품인지 알 수 없는 안내는 따라 할 수 없습니다.
- **자주 묻는 질문을 뺐습니다.** 드리미·LG 답변은 브랜드 자료로 확인되지 않았습니다. 드리미는 공식 안내를 기준으로 쓴 별도 글로 연결했습니다.
