드리미 로봇청소기가 청소를 마치고도 도크(베이스 스테이션)로 돌아오지 않는 경우는 크게 세 가지입니다. **도크를 못 찾는 경우**, **도크에는 올라갔는데 충전이 안 되는 경우**, **도크 앞에서 붙었다 떨어졌다를 반복하는 경우**입니다. 드리미 고객지원이 안내하는 순서대로, 쉬운 것부터 확인해 보세요.

![드리미가 도크로 안 돌아올 때 점검 순서 — 1 도크 전원과 뒤쪽 스위치(표시등이 켜지는지), 2 도크 앞 1~2m에서 복귀 버튼 시험(되면 자리 문제), 3 벽에 붙이고 앞 1.5m 비우기(양옆 0.5m·평평한 곳), 4 라이다·반사 필름·바퀴·접점 닦기(전원 끄고 마른 천)](/images/flow_dreame_dock_check.svg)

## 먼저 나누기: 못 찾는 건지, 올라가도 충전이 안 되는 건지

- **로봇이 도크 근처에도 오지 못하고 멈춘다** → 1~4단계
- **도크에 올라가 있는데 배터리가 오르지 않는다** → 1단계와 5단계
- **도크 앞에서 붙었다 떨어졌다를 반복한다** → 6단계

청소 중에 로봇이 어딘가에 끼어 알림을 띄웠거나 배터리가 다 떨어졌다면, 드리미 안내대로 **로봇을 손으로 도크에 올려** 충전합니다. 이 경우는 고장이 아닙니다.

## 1단계: 도크 전원과 뒤쪽 스위치

드리미 고객지원이 가장 먼저 보라고 하는 곳입니다.

{{< check title="도크 전원 확인 (드리미 고객지원)" >}}
1. 도크 **전원선 양쪽 끝**(콘센트 쪽과 도크 쪽)이 제대로 꽂혀 있는지, 어댑터 플러그가 헐겁지 않은지 본다
2. 도크 **뒤쪽 스위치**(로커 스위치)가 켜짐(ON) 쪽에 있는지 본다 — 스위치가 있는 모델만
3. 도크의 **표시등이 켜져 있는지** 본다
4. 어댑터가 손상됐다면 여분 어댑터로 바꿔 충전해 본다
{{< /check >}}

## 2단계: 도크 앞 1~2m에서 복귀 버튼으로 시험

전원이 정상이라면, 로봇이 도크를 찾을 수 있는지 직접 시험합니다. 드리미 고객지원은 **로봇을 도크 앞 1~2m에 놓고 복귀(충전) 버튼을 짧게 눌러** 돌아가는지 보라고 안내합니다.

- **돌아간다** → 로봇은 정상이고, 평소 자리에서 도크를 찾기 어려운 것입니다. 3·4단계로 갑니다.
- **1m 앞에서도 돌아가지 못한다** → 다른 안내(«The robot cannot find the base station»)는 이 경우 고객지원에 문의하라고 합니다. 그 전에 4~7단계를 해 볼 수 있습니다.

## 3단계: 도크 자리 다시 보기

드리미 고객지원의 도크 배치 기준입니다.

| 확인할 것 | 드리미 고객지원 안내 |
|---|---|
| 벽 | 도크를 **벽에 붙여** 놓기 |
| 앞쪽·양옆 | **앞쪽 1.5m** 안에 장애물이 없게, **양옆은 0.5m씩** 비우기 |
| 바닥 | 도크 둘레 **1m 안은 트이고 평평하게**. 울퉁불퉁한 바닥은 피하기 |
| 주변 기기 | **공유기·TV 같은 신호 간섭 기기**에서 떨어뜨리기 |
| 맞은편 | 도크 맞은편에 **거울·창문처럼 비치는 것**이 없게 — 로봇의 길 찾기에 영향 |
| 가는 길 | 도크와 청소 구역 사이 길을 막는 물건 치우기 |

![도크를 벽에 붙이고 앞쪽 1.5m·양옆 0.5m를 비우며, 공유기·TV 옆, 맞은편 거울·창문, 울퉁불퉁한 바닥, 청소 중 도크 옮기기를 피하는 배치 그림](/images/art_dreame_dock_place.svg)

**도크를 옮겼다면** 드리미 안내는 두 가지입니다.

- 새 자리의 도크에 로봇을 올려 두고, **도크에서 청소를 시작**해 시험합니다.
- 앱에서 로봇을 원격으로 도크에 돌려보내도 됩니다. 다음에 로봇이 도크를 떠나 청소를 시작할 때 도크 위치가 자동으로 바뀝니다.

## 4단계: 센서·반사 필름·바퀴 닦기

로봇은 위쪽의 라이다(레이저 센서)로 집 안 위치를 잡고, 도크 앞면의 표시를 보고 도크를 찾습니다. 드리미 고객지원은 아래를 확인하라고 합니다.

{{< check title="닦고 확인할 곳 (드리미 고객지원)" >}}
1. 로봇 위쪽 **라이다**가 깨끗하고 가린 것이 없는지 — 도크에서 청소를 시작할 때 라이다가 돌아가는지, 이상한 소리가 나지 않는지도 본다
2. 도크의 **반사 필름**(앞면 표시)이 깨끗하고 가려지지 않았는지
3. **구동 바퀴와 도크 바닥판**에 진흙·먼지가 없는지 — 돌아오다 바퀴가 미끄러지거나 걸리면 닦는다
{{< /check >}}

![닦을 곳 — 로봇 위쪽 라이다(가린 것 없이 깨끗하게), 도크 반사 필름(얼룩·가림 없이), 구동 바퀴와 도크 바닥판(진흙·먼지 없이)](/images/art_dreame_dock_clean.svg)

## 5단계: 올라가는데 충전이 안 된다면

도크에는 올라가 있는데 배터리가 오르지 않는다면 접점 문제일 수 있습니다.

{{< check title="충전이 안 될 때 (드리미 고객지원)" >}}
1. **전원을 끈 뒤** 도크와 로봇의 **충전 접점**을 닦는다
2. 도크의 충전 접점(스프링처럼 눌리는 부분)이 눌렀다 놓으면 **다시 튀어나오는지** 본다
3. 로봇이 도크에 **바르게** 올라가 있는지 본다 — 거꾸로 놓이지 않았는지
4. 바르게 올려 **2~3시간** 충전한 뒤, 앱에서 배터리가 오르는지 본다
{{< /check >}}

## 6단계: 도크에 붙었다 떨어졌다를 반복한다면

드리미 고객지원의 «반복 도킹» 안내입니다. 물걸레 세척판이 있는 도크 모델 기준입니다.

1. 충전 접점과 로봇 충전부를 닦고, **구동 바퀴에 낀 것**이 없는지 봅니다.
2. 걸레와 **세척판(워시보드)을 빼서 다시 단단히 끼웁니다.**
3. **도크 전원을 빼고 약 2분 기다린 뒤** 다시 꽂고, 로봇도 다시 켭니다. 그다음 로봇을 다시 도크로 불러 봅니다.
4. 같은 안내에는 도크의 도킹 부분에 그리스(윤활제)를 조금 바르고 남은 것은 닦아 내라는 단계도 있습니다. 바를 자리는 원문 그림으로 안내돼 있으니, 직접 하기 전에 고객지원에 위치를 확인하는 편이 안전합니다.

![올라가는데 충전이 안 되거나 붙었다 떨어졌다 할 때 — 전원 끄고 접점 닦기(도크 접점이 다시 튀어나오는지), 도크 전원 약 2분 끄기(로봇도 다시 켜고 복귀), 바르게 올려 2~3시간(앱에서 배터리가 오르는지)](/images/art_dreame_dock_charge.svg)

## 7단계: 재시작, 재설정, 지도 다시 만들기, A/S

위를 다 해 봐도 안 되면 가벼운 것부터 해 봅니다.

1. **재시작**: 로봇을 껐다 켜고 다시 청소해 봅니다.
2. **재설정**: 재시작으로도 안 되면 로봇을 재설정합니다. 드리미 안내대로 재설정 뒤에는 도크를 **트인 곳으로 옮겨** 다시 청소해 봅니다. **재설정하면 공장 설정으로 돌아갑니다.** 버튼 위치는 모델마다 다르니 설명서의 재설정 항목을 확인하세요.
3. **지도 다시 만들기**: 드리미 고객지원은 그래도 문제가 계속되면 로봇의 위치 인식 문제일 수 있으니 **지도를 다시 만들어 보라**고 안내합니다. 도크에서 출발시켜 처음부터 그리게 합니다.
4. **A/S**: 여기까지 해도 안 되면 수리가 필요한 상태입니다. 드리미 고객센터(앱의 고객 지원 메뉴 또는 공식 홈페이지)로 접수하세요.

재설정 뒤 앱 연결이 끊겼다면 [드리미 네트워크 연결 오류 점검 순서](/posts/드리미-네트워크-연결-오류-점검-순서/)를 참고하세요.

## 고객지원에 문의할 때 알려 줄 것

- 모델명과 기기 일련번호(앱이나 본체·도크 라벨)
- 증상이 어느 쪽인지(도크를 못 찾음 / 올라가도 충전 안 됨 / 붙었다 떨어졌다 반복)
- **2단계 시험 결과**(도크 앞 1~2m에서 복귀 버튼을 눌렀을 때 돌아갔는지)
- 도크 표시등 상태, 앱에 뜬 오류 문구, 도크 주변 사진
- 해외 직구 제품은 국내 보증 적용 여부가 다를 수 있으니 구매처 조건도 확인하세요.

## 다시 생기지 않게 하려면

- 청소는 되도록 **도크에서 출발**시키고, 도크를 옮겼다면 새 자리의 도크에서 출발시킵니다.
- 도크 앞 1.5m와 양옆 0.5m에 물건을 두지 않습니다.
- 라이다, 도크 반사 필름, 바퀴, 충전 접점을 가끔 마른 천으로 닦습니다.

## 왜 이렇게 썼나

- **복귀 시험 거리를 «1~2m»로 적었습니다.** 드리미 고객지원 안내 중 «Why Can’t My Robot Find Its Charging Dock?»은 1~2m, «The robot cannot find the base station»은 약 1m에서 시험하라고 합니다. 두 안내를 합쳐 1~2m로 적고, 1m에서도 안 되면 문의하라는 안내를 함께 적었습니다.
- **도크 둘레 기준이 두 가지입니다.** 배치 안내는 «앞 1.5m·양옆 0.5m», 복귀 안내는 «둘레 1m는 트이고 평평하게»입니다. 둘이 겹치는 기준이라 표에 모두 적었습니다. 로보락 고객지원의 일반 안내(앞 1.5m·양옆 0.5m)와 같은 값입니다.
- **그리스 바르기는 위치 확인을 권했습니다.** 원문은 바를 자리를 그림으로만 보여 주고, 어느 모델에 해당하는지 적지 않았습니다. 잘못 바르면 접점을 더럽힐 수 있어, 직접 하기 전에 고객지원에 확인하라고 적었습니다.
- **재설정 버튼을 누르는 방법은 적지 않았습니다.** 드리미 안내는 «재설정하면 공장 설정으로 돌아간다»는 주의만 적고 있고, 버튼 위치·누르는 시간은 모델마다 다릅니다.
