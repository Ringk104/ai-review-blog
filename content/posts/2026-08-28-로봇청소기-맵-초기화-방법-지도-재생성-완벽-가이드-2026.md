> 이 글은 삼성전자서비스 공식 안내(맵 삭제 후 재설정·충전복귀)와 로보락 고객지원·공식 사용설명서(S7·Qrevo 2 Pro 영문판)를 바탕으로 AI가 정리하고 운영자가 확인했습니다. 2026-11-12 에 전면 다시 썼습니다 — 고친 이유는 아래 «왜 이렇게 썼나»에 있습니다.

{{< action title="지도가 틀어졌다면, 이 순서로" >}}
1. 충전대(스테이션)를 **옮기거나 돌린 적이 있는지** 본다 — 있다면 지도를 다시 만드는 것이 맞다
2. 방 경계만 틀렸다면 지우기 전에 **앱의 방 나누기·합치기**로 고쳐 본다
3. 지도를 지우기로 했다면 **바닥을 치우고 방문을 연 뒤** 지운다
4. 앱에서 **지도 삭제 → 새 지도 만들기(공간학습·맵핑)**를 하고, 끝날 때까지 로봇을 건드리지 않는다
{{< /action >}}

지도를 지우면 그 지도에 그려 둔 **방 이름, 금지 구역, 가상 벽, 예약 청소 설정**을 다시 해야 할 수 있습니다. 그래서 «틀어졌다»고 느낄 때 바로 지우기보다, 왜 틀어졌는지 먼저 보는 것이 순서입니다.

## 지도를 다시 만들어야 하는 경우

{{< check title="제조사가 «지도를 다시 만들라»고 하는 경우" >}}
1. **삼성**: 청정스테이션을 설치한 뒤 **45도 이상 돌리거나 1m 이상 옮겼을 때** — 기존 지도를 쓰면 청소되지 않는 곳이 생길 수 있다(삼성전자서비스)
2. **로보락**: 앱의 지도가 **비스듬하게(가로·세로가 아니게)** 보일 때 — 도크 위치 때문일 수 있어, 도크를 옮긴 뒤 지도를 새로 만든다(로보락 고객지원)
3. **로보락**: 로봇을 **손으로 크게 옮기거나 스팟 청소를 한 뒤** — 로봇이 지도를 새로 만들기 때문에, 도크가 멀면 돌아가지 못할 수 있다(S7·Qrevo 2 Pro 설명서)
{{< /check >}}

로보락 S7 설명서는 **로봇을 손으로 옮기거나 집 안 환경을 크게 바꾸면 금지 구역·가상 벽이 사라질 수 있다**고도 적습니다. 가구 배치를 크게 바꾼 뒤 금지 구역이 이상하게 동작한다면 지도를 다시 만드는 쪽이 깔끔합니다.

## 지우기 전에 해 볼 것

![지도 그리기](/images/art_lidar.svg)

- **방 경계만 틀렸을 때**: 로보락 앱은 지도 편집에서 **방을 합치거나 나눌 수** 있습니다(로보락 고객지원). 삼성은 맵을 만든 뒤 청소 제외구역과 가상 벽을 설정할 수 있습니다(삼성전자서비스).
- **도크로 못 돌아갈 때**: 지도보다 도크 주변 공간이 문제일 수 있습니다. 로보락은 도크 **양옆 0.5m·앞 1.5m**, 삼성은 충전기 **좌우 0.5m·앞 1m** 안에 장애물이 없게 하라고 안내합니다. 자세한 점검은 [로보락이 충전 도크로 복귀하지 않을 때](/posts/로보락-충전-도크로-복귀하지-않을-때-점검-순서/)에 정리했습니다.
- **로보락 백업 지도가 있을 때**: 로보락 고객지원의 지도 재설정 안내 화면에는 «현재 지도»와 함께 **«백업 지도»**가 있고, 백업 지도를 골라 다시 쓸 수 있습니다. 예전에 잘 맞던 지도가 백업돼 있다면 지우기 전에 먼저 확인해 봅니다(백업 기능 유무는 모델·앱 버전에 따라 다름).

## 삼성 — 스마트싱스에서 맵 삭제 후 다시 만들기

{{< check title="삼성 로봇청소기 맵 재설정 (삼성전자서비스)" >}}
1. 스마트싱스(SmartThings) 앱 실행 → 아래쪽 **[기기]** → 로봇청소기 선택
2. 메뉴를 위로 올려 **맵 관리** 선택
3. **맵 삭제**를 눌러 쓰던 맵 삭제
4. **공간학습** → **시작** — 로봇이 청소 없이 먼저 돌아다니며 맵을 그린다
5. 맵 그리기가 끝나면 로봇이 복귀하고, 앱에 학습된 맵이 표시된다
6. 맵에서 **청소 제외구역·가상벽**을 다시 설정
{{< /check >}}

공간학습 중에는 로봇이 «현재 위치를 확인합니다», «맵 그리기를 마무리합니다» 같은 음성 안내를 하고, 끝나면 청소가 필요한 면적과 예상 시간을 알려 줍니다(삼성전자서비스). 맵을 처음 그리는 자세한 순서는 [삼성 로봇청소기 맵 그리기 가이드](/posts/삼성-로봇청소기-맵-그리기-완벽-가이드-비스포크-제트봇-맵핑-설정법-2026/)에 있습니다.

{{< callout kind="warn" title="«기기 초기화»와 다릅니다" >}}
맵만 다시 만들 때는 위의 «맵 삭제 → 공간학습»을 씁니다. 로봇 자체를 공장 상태로 되돌리는 «기기 전체 초기화»를 하면 스마트싱스 앱에서 로봇이 오프라인이 되고 **다시 등록해야** 합니다(삼성전자서비스, 2026 비스포크 AI 스팀 기준). 맵 문제라면 기기 초기화까지 갈 필요가 없습니다.
{{< /callout >}}

## 로보락 — 앱에서 지도 지우고 새로 만들기

{{< check title="로보락 지도 재설정 (로보락 고객지원 안내 화면 기준)" >}}
1. Roborock 앱에서 로봇을 선택해 지도 화면으로 들어간다
2. 지도 메뉴에서 **지도 관리(Manage map)** 선택
3. **현재 지도(Current map)** 아래 **삭제(Delete)**
4. 다음 청소를 시작하면 로봇이 새 지도를 만든다 — 끝날 때까지 로봇을 손으로 옮기지 않는다
{{< /check >}}

- 로보락 고객지원의 안내 화면은 예전 앱(로보락 S6) 기준이라 메뉴 위치가 지금 앱과 다를 수 있습니다. 설명서도 **앱 기능은 업데이트로 바뀔 수 있다**고 적습니다.
- 지도가 비스듬할 때는 **지도 저장(Map Saving)을 껐다가 다시 켜면** 다음 청소에서 새 지도를 만든다고 로보락 고객지원이 안내합니다.
- S7 설명서에 따르면 **방 선택 청소와 예약 청소는 지도 저장이 켜져 있고 전체 청소를 한 번 마친 뒤에** 쓸 수 있습니다. 새 지도를 만들었다면 먼저 전체 청소를 한 번 끝까지 돌립니다.

## 새 지도를 잘 만드는 법

제조사 안내에 공통으로 나오는 준비만 옮깁니다.

- **도크·충전기 자리를 먼저 정한다**: 새 지도는 도크 위치를 기준으로 만들어지므로, 지도를 만든 뒤 도크를 옮기면 다시 만들어야 할 수 있습니다(삼성 45도·1m 기준). 도크는 평평한 바닥에 벽에 붙여 둡니다.
- **바닥의 전선·작은 물건을 치운다**: 로보락 Qrevo 2 Pro 설명서는 청소 전에 전선과 귀중품을 바닥에서 치우라고 적습니다.
- **스테이션에서 출발시킨다**: Qrevo 2 Pro 설명서는 로봇이 도크로 잘 돌아오게 하려면 **도크에서 출발시키고 청소 중에는 도크를 옮기지 말라**고 적습니다.

{{< callout kind="stop" title="그래도 지도가 계속 틀어지면" >}}
지도를 새로 만들어도 금방 틀어지거나, 같은 곳에서 위치를 잃는다면 센서 문제일 수 있으니 제조사 고객지원에 문의합니다. 모델명, 앱에서 본 지도 화면(캡처), 도크를 옮긴 적이 있는지, 위 순서 중 어디까지 해 봤는지를 함께 알려 주면 빠릅니다.
{{< /callout >}}

## 왜 이렇게 썼나

이 글의 8월 판은 리뷰를 AI로 요약해 만든 글이었습니다. 2026-11-12 에 제조사 자료와 대조해 다시 썼습니다.

- **근거 없는 숫자를 뺐습니다.** «맵 오류의 70% 이상은 환경 요인», «맵을 관리하면 만족도 30% 이상», «3~6개월마다 재생성» 같은 숫자는 확인할 수 있는 근거가 없어 지웠습니다.
- **도크 거리 숫자를 제조사 값으로 바꿨습니다.** 8월 판은 «벽에서 30cm, 양옆 50cm»라고 적었지만, 로보락은 양옆 0.5m·앞 1.5m, 삼성은 좌우 0.5m·앞 1m를 안내합니다. 도크는 벽에서 띄우지 않고 **벽에 붙이는** 것이 두 제조사 공통입니다.
- **확인되지 않은 메뉴 경로를 지웠습니다.** 에코백스(«본체 리셋 버튼 5초»)·LG(ThinQ 메뉴 경로)는 제조사 자료로 확인하지 못해 뺐습니다. 삼성과 로보락만 공식 안내 순서로 적었습니다.
- **«도크를 옮기면 꼭 초기화»를 고쳤습니다.** 삼성은 45도 이상 회전·1m 이상 이동이라는 기준을 둡니다. 조금 옮긴 정도까지 지울 필요는 없습니다.
- **판매가 끝난 제품 추천을 뺐습니다.** 8월 판 첫머리에 추천한 삼성 비스포크 제트봇 AI(VR50T95935W)는 11-10 쿠팡에서 본체가 보이지 않았고, 이 글의 주제와도 거리가 있어 뺐습니다.
