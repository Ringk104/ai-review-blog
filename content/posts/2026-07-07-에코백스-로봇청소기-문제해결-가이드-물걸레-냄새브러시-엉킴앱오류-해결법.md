## 1. 물걸레 패드 세척하고 자연 건조

에코백스 고객지원에서 물걸레 냄새만 따로 다룬 안내는 찾지 못했습니다. 다만 물걸레 패드를 **떼어 세척하고 말린 뒤 다시 쓰라는** 관리 안내는 있습니다. 젖은 패드를 그대로 두지 않는 것이 기본입니다.

{{< check title="물걸레 패드 떼고 세척하기 (에코백스 한국 고객지원)" >}}
- 로봇을 **뒤집어 부드러운 바닥 매트 위**에 놓는다
- **물걸레 패드 판**을 살짝 들어 올려 분리하고, 판에서 **물걸레 패드**를 떼어 낸다
- 패드를 세척하고 **건조한 뒤** 다시 쓴다 — 디봇 N30 PRO OMNI 안내는 «세척 후 **자연 건조**»라고 적고 있다
- 다시 끼울 때는 패드를 판에 평평하게 맞춰 붙이고, 판을 로봇에 끼워 **딸깍** 소리가 나는지 확인한다
{{< /check >}}

패드 판을 돌려서 빼는 모델도 있고 들어 올려 빼는 모델도 있습니다. 힘으로 당기기 전에 내 모델 설명서에서 빼는 방향을 확인하세요.

![물걸레 패드 관리 — 로봇을 부드러운 매트 위에 뒤집고, 물걸레 패드 판을 분리해 패드를 떼어 세척한 뒤 자연 건조하고, 다시 끼울 때 딸깍 소리를 확인한다(에코백스 한국 고객지원 · 디봇 N30 PRO OMNI)](/images/art_ecovacs_mop.svg)

## 2. 스테이션 오수통과 세척 트레이 청소

물걸레를 자동으로 빨아 주는 스테이션(OMNI 계열 등)은 걸레를 빤 물이 **오수통**에 모이고, 걸레를 문지르는 **세척 트레이**에 머리카락과 먼지가 쌓입니다. 에코백스 안내에 있는 관리 방법은 이렇습니다.

- **오수통을 비우고 청소한다.** 에코백스 미국 고객지원의 스테이션 셀프 클리닝 안내는 스테이션 윗덮개를 열고 오수통을 빼서 비우라고 합니다. 한국 고객지원 소음 안내도 오수통이 막혔는지 확인하고, 먼저 물탱크를 청소하라고 안내합니다.
- **세척 트레이를 뺀다.** 세척 트레이에 머리카락이나 먼지가 많으면 **해제 버튼**을 눌러 트레이를 빼서 청소한 뒤 다시 끼웁니다(에코백스 미국 고객지원).
- **스테이션 먼지통도 비운다.** 에코백스 미국 고객지원은 습한 날씨나 젖은 쓰레기를 많이 빨아들이면 스테이션 먼지통 안 쓰레기가 오래 보관되며 **곰팡이가 피고 냄새가 날 수 있다**고 안내합니다. 기기 기능에는 영향이 없고, 청소 뒤 제때 비워 **MAX 선 아래**로 유지하라고 합니다.
- **새 스테이션의 냄새는** 처음 쓸 때 약간의 소재 냄새가 나다가 쓰면서 점점 사라진다고 안내합니다(에코백스 미국 고객지원).
- **스테이션 바닥이 젖으면** 걸레 패드가 스테이션을 빠져나올 때 물을 많이 머금고 있어서일 수 있습니다. 한국 고객지원은 스테이션을 잠시 옮겨 바닥을 닦거나, 에코백스 에코백스 전용 «흡입 패드»를 쓰라고 안내합니다.

건조 기능이 있는 스테이션에서 건조할 때 소음이 나면, 한국 고객지원은 **스테이션 전원을 껐다 켜고 앱에서 건조 기능을 다시 켜** 보고, 그래도 계속되면 A/S 센터에 문의하라고 안내합니다. 자동 먼지비움이 안 되는 경우는 [로봇청소기 먼지비움 안됨 해결법](/posts/로봇청소기-먼지비움-안됨-해결법-클린베이스-점검-체크리스트-2026/)을 보세요.

![스테이션 관리 — 오수통을 꺼내 비우고 막혔는지 보고, 세척 트레이는 해제 버튼을 눌러 빼서 머리카락·먼지를 청소하고, 먼지통은 MAX 선 아래로 제때 비운다(에코백스 한국·미국 고객지원)](/images/art_ecovacs_station.svg)

## 3. 물걸레가 돌지 않을 때

회전형 물걸레(물걸레 브래킷·패드 판) 모델에서 물걸레가 안 돌면, 한국 고객지원은 이 순서로 보라고 안내합니다.

1. **물걸레 트레이에 이물질**이 끼었는지 보고 청소한다
2. 앱에서 **«카펫 설정»이 «자동 적응 카펫 모드»**인지 확인한다
3. 물걸레 트레이를 **뺐다가 다시 끼운다**

고장이 아닌 경우도 있습니다. **쓸기 모드**에서는 물걸레 브래킷이 올라가 있어 돌지 않고, 물걸레 모드라도 **카펫을 만나면** 브래킷이 자동으로 올라가 돌지 않습니다. 충전하러 스테이션으로 돌아갈 때도 물걸레 트레이 전체가 올라갑니다. 청소 모드는 ECOVACS HOME 앱의 로봇 제어 화면에서 확인할 수 있습니다.

**한쪽만 안 돌면** 본체를 뒤집어 물걸레 홀더에 감긴 것을 빼고, 그래도 같으면 왼쪽·오른쪽 물걸레 트레이를 **서로 바꿔 끼워** 봅니다. 그래도 안 돌면 A/S 점검을 받으라고 안내합니다.

## 4. 메인 브러시에 감긴 머리카락 빼기

에코백스 글로벌 고객지원은 청소 중에 메인 브러시나 사이드 브러시가 돌지 않으면 **머리카락이나 이물이 감겼을 수 있다**고 안내합니다.

{{< check title="메인 브러시 빼서 청소하기 (에코백스 글로벌·한국 고객지원)" >}}
- 디봇의 **전원을 끄고** 바닥이 위로 오게 **뒤집는다**
- **메인 브러시 덮개**의 양쪽 탭을 눌러 덮개를 빼고, **메인 브러시**를 꺼낸다
- 로봇에 들어 있는 **청소 도구**로 감긴 머리카락을 **잘라 내서** 뺀다
- 메인 브러시 **양쪽 끝(베어링)**에 감긴 머리카락도 모두 뺀다
- 메인 브러시는 물로 헹굴 수 있지만, **완전히 말린 뒤** 다시 끼운다
- 끼운 뒤 덮개를 닫기 전에 브러시를 **손으로 돌려** 부드럽게 도는지 보고, **딸깍** 소리가 나게 끼운다
{{< /check >}}

**사이드 브러시**는 빼서 브러시와 끼우는 자리를 **마른 천**으로 닦은 뒤 다시 끼웁니다(에코백스 글로벌 고객지원). 덮개 여는 방식(탭을 누르는지, 덮개를 누르는지)은 모델마다 다릅니다.

![메인 브러시 청소 — 전원을 끄고 뒤집어 메인 브러시 덮개의 양쪽 탭을 눌러 빼고, 청소 도구로 감긴 머리카락을 잘라 내고 양쪽 끝 베어링까지 뺀 뒤, 물로 헹궜다면 완전히 말려 다시 끼운다(에코백스 글로벌·한국 고객지원)](/images/art_ecovacs_brush.svg)

브러시 엉킴을 줄이는 방법은 [로봇청소기 브러시 엉킴 예방·제거](/posts/로봇청소기-브러시-엉킴-예방제거-완벽-가이드-머리카락-관리법-2026/)에, 바퀴에 감긴 경우는 [로봇청소기 바퀴 엉킴 해결법](/posts/로봇청소기-바퀴-엉킴-해결법-브러시-머리카락-제거-2026/)에 정리했습니다.

## 5. 시끄러운 소리를 내며 멈출 때

한동안 청소하다가 시끄러운 소리를 내며 멈추면, 한국 고객지원은 이렇게 보라고 안내합니다.

1. **먼지통**을 빼서 비운다
2. **메인 브러시**를 청소한다 — 양쪽 끝 베어링에 감긴 머리카락까지 뺀다
3. **사이드 브러시**를 확인하고 청소한다
4. **필터**를 청소하고 교체한다

평소보다 소리가 크기만 하다면 앱에서 흡입력을 **«표준»**으로 바꿔 봅니다. 한국 고객지원은 **«초강력»·«강력»** 모드에서는 소리가 뚜렷하게 커진다고 안내합니다. 필터가 젖었다면 충분히 말린 뒤 씁니다.

청소 전에 **전선과 작은 물건**을 치워 두면 바퀴·메인 브러시·사이드 브러시에 감기는 일을 줄일 수 있습니다. 치울 수 없는 곳은 앱 지도에서 **가상 경계**를 그어 두면 디봇이 그 안으로 들어가지 않습니다(에코백스 미국 고객지원, 디봇 N7). 청소 중 자주 멈추는 다른 원인은 [로봇청소기 멈춤 원인 체크리스트](/posts/로봇청소기-멈춤-원인-체크리스트-작동-중단-해결-가이드-2026/)를 보세요.

## 6. 앱 연결이 안 될 때 (ECOVACS HOME)

ECOVACS HOME 앱에 로봇이 등록되지 않으면, 에코백스 한국 고객지원의 홈 Wi-Fi 연결 문제 해결 안내를 이 순서로 봅니다.

{{< check title="앱 등록 전에 확인할 것 (에코백스 한국 고객지원)" >}}
- **ECOVACS HOME 앱**을 최신 버전으로 업데이트하고, 휴대폰 설정에서 앱의 **데이터·Wi-Fi·위치(GPS 포함)** 권한을 켠다
- 휴대폰을 홈 Wi-Fi에 연결하고 **모바일 데이터(4G/5G)를 끈다**
- 공유기는 **2.4GHz**만 지원한다 — 2.4GHz와 5GHz가 따로 있으면 **2.4GHz**를 고른다
- **VPN·프록시**, 웹 로그인 방식 Wi-Fi, **숨긴 SSID**는 지원하지 않는다
- 네트워크 이름이 **«알 수 없는 SSID»**로 보이면 앱의 **위치** 권한을 켠다
{{< /check >}}

앱에서 **기기 추가**로 들어가 안내를 따르다가, 로봇의 **재설정(RESET)** 버튼을 눌러 «네트워크 설정 모드» 음성이 나오면 다음 단계로 넘어갑니다. 진행률이 **50%**를 넘으면 휴대폰이 설정에 고른 Wi-Fi에 다시 연결돼 있는지 확인하세요. 일부 안드로이드 휴대폰에 «이 WLAN에 연결할 수 없습니다» 같은 창이 뜨면, 네트워크를 바꾸지 않는 쪽(«전환하지 않음», «아니요»)이나 지금 네트워크를 계속 쓰는 쪽(«네»)을 고릅니다.

계속 실패하면 한국 고객지원은 백신 앱·VPN을 끄고 다시 해 보거나, **다른 휴대폰의 모바일 핫스팟**으로 설정해 보라고 안내합니다. 로봇 Wi-Fi 표시등이 깜박이지 않으면 연결이 끝난 것입니다. 공유기 쪽 점검은 [로봇청소기 Wi-Fi 연결 안될 때 해결법](/posts/로봇청소기-wi-fi-연결-안될-때-해결법-완벽-가이드-2026/)에 더 자세히 정리했습니다.

## 7. 네트워크 오류 코드 보는 법

앱 등록 중에 숫자 오류 코드가 뜨면, 에코백스 한국 고객지원의 네트워크 오류 코드 표에서 뜻을 찾을 수 있습니다. 표에 있는 것만 옮깁니다.

| 오류 코드 | 뜻 | 할 일 |
|---|---|---|
| 10016, 10017 (406) | 장치 구성 시간 초과 | 모바일 데이터 끄기, 로봇 Wi-Fi(ECOVACS_xxxx)가 안 보이면 로봇·공유기 재시작 후 앱 다시 실행 |
| 2, 10002, 10024 | 프로그램 오류 | 앱 다시 열고 로봇 재시작 후 다시 설정 |
| 3 | 잘못된 로그인 | 계정에 다시 로그인 후 다시 설정 |
| 10000, 10020, 10021 | 휴대폰 연결 끊김 | 휴대폰과 홈 Wi-Fi가 모두 인터넷에 연결됐는지 확인 |
| 10006, 10011 | 네트워크 설정 시간 초과 | 휴대폰과 홈 Wi-Fi가 모두 인터넷에 연결됐는지 확인 |
| 10010, 10018, 10025 | 로봇을 네트워크에 연결할 수 없음 | 로봇을 공유기 가까이(약 3m 이내), Wi-Fi 비밀번호·2.4GHz·같은 Wi-Fi인지 확인 |
| 10503 | 설정 정보 받기 시간 초과 | 진행률 50% 전까지 휴대폰이 ECOVACS_xxxx에 붙어 있게, 삼성 휴대폰은 «모바일 데이터로 전환» 끄기 |

406은 홈 Wi-Fi 연결 문제 해결 안내에 10017과 함께 «장치 구성 타임아웃»으로 적혀 있습니다. 표에 없는 코드는 «알 수 없는 오류»로, 다시 시도하라고 안내합니다. 로봇 본체가 내는 오류 음성이나 앱의 기기 오류 알림은 모델마다 달라 이 글에서는 다루지 않았습니다. 내 모델 설명서나 고객지원의 모델별 페이지를 확인하세요.

## 왜 이렇게 고쳤나
