> 이 글은 삼성전자서비스 공식 안내(맵 삭제 후 재설정·충전복귀·골고루 청소 안 될 때·제트봇 AI 소개·진입 방지 테이프)를 바탕으로 AI가 정리하고 운영자가 확인했습니다. 2026-11-12 에 전면 다시 썼습니다 — 고친 이유는 아래 «왜 이렇게 썼나»에 있습니다.

{{< action title="삼성 로봇청소기 맵, 이 순서로 그리세요" >}}
1. **충전기(청정스테이션) 자리부터** 정한다 — 평평한 바닥, 벽에 붙여, 좌우 0.5m·앞 1m 비우기
2. 바닥의 **의자·전선·빨래 건조대**를 치운다
3. 스마트싱스 앱 → [기기] → 로봇청소기 → **맵 관리 → 공간학습 → 시작**
4. 맵이 완성되면 **청소 제외구역·가상벽**을 그린다
{{< /action >}}

삼성 로봇청소기는 스마트싱스(SmartThings) 앱에서 **«공간학습»**으로 맵을 그립니다. 로봇이 청소하지 않고 먼저 집 안을 돌아다니며 맵을 만들고, 다 그리면 충전기로 돌아갑니다(삼성전자서비스). 맵은 충전기 위치를 기준으로 쓰이기 때문에, **충전기 자리를 먼저 정하는 것**이 가장 중요합니다.

## 1. 그리기 전에 — 충전기 자리

{{< check title="충전기(청정스테이션) 자리 고르기 (삼성전자서비스)" >}}
1. 로봇이 쉽게 찾을 수 있고 **바닥과 벽이 평평한 곳**
2. **벽에 밀착**해서 둔다
3. 충전기 **좌우 0.5m 이상, 앞 1m 이상** 비워 둔다
4. **좁은 통로나 방문 근처는 피한다** — 충전기 신호 때문에 로봇이 일부 공간에 들어가지 못하거나 복귀할 때 방향을 잡지 못할 수 있다
5. 전원을 연결하고 충전기 **전원 표시등에 빨간 불**이 켜지는지 확인
{{< /check >}}

삼성전자서비스는 충전기 전면이 잘 보이는 **거실**에 두어야 충전복귀를 잘 한다고 안내합니다. 로봇과 충전기가 적외선으로 통신하기 때문입니다.

{{< callout kind="warn" title="맵을 그린 뒤 충전기를 옮기면" >}}
청정스테이션을 설치한 뒤 **45도 이상 돌리거나 1m 이상 옮기면 맵을 다시 만들라**고 삼성전자서비스는 안내합니다. 기존 맵을 그대로 쓰면 청소되지 않는 곳이 생길 수 있습니다. 그래서 충전기 자리를 먼저 확정하고 나서 맵을 그립니다.
{{< /callout >}}

## 2. 그리기 전에 — 바닥 정리

삼성전자서비스는 일부 구역을 청소하지 못하는 원인으로 **식탁 의자, 전선, 빨래 건조대** 같은 장애물을 듭니다. 맵을 그릴 때도 로봇이 다닐 수 있는 공간이 넓어야 맵에 빠지는 곳이 없습니다.

- 식탁 의자는 로봇이 지나갈 수 있게 정리
- 바닥의 전선, 빨래 건조대 치우기
- 맵에 넣고 싶은 방은 문을 열어 두기

## 3. 공간학습으로 맵 그리기

{{< check title="스마트싱스 공간학습 (삼성전자서비스)" >}}
1. 스마트싱스 앱 실행 → 아래쪽 **[기기]** → 로봇청소기 선택
2. 메뉴를 위로 올려 **맵 관리** 선택
3. 이미 쓰던 맵이 있으면 **맵 삭제**
4. **공간학습** → **시작**
5. 로봇이 «청소전 먼저 자율주행하며 맵을 그릴께요» 하고 출발 → «현재 위치를 확인합니다» → «맵 그리기를 마무리합니다» 후 복귀
6. 앱에 학습된 맵이 표시되고, 로봇이 청소가 필요한 면적과 예상 시간을 알려 준다
{{< /check >}}

공간학습 중에는 로봇을 손으로 옮기거나 충전기를 건드리지 않는 것이 좋습니다. 앞에서 본 것처럼 충전기 위치가 바뀌면 맵을 다시 만들어야 할 수 있습니다.

## 4. 다 그린 뒤 — 제외구역·가상벽·지정 청소

- 맵이 표시되면 그 맵에서 **청소 제외구역과 가상벽**을 설정할 수 있습니다(삼성전자서비스 맵 재설정 안내).
- 스마트싱스 앱으로 **지정 청소 구역**을 설정하고, 원하는 방만 골라 청소하거나 **예약 청소**를 할 수 있습니다(삼성전자서비스 제트봇 AI 안내).
- 반려동물 밥그릇 주변처럼 로봇이 들어가지 않았으면 하는 곳을 제외구역으로 그려 둡니다. 다만 로보락 S7 설명서는 금지 구역·가상벽을 **청소 범위를 정하는 용도로만 쓰고 위험한 곳을 막는 데 쓰지 말라**고 적습니다. 브랜드는 다르지만 같은 원리이니, 계단처럼 떨어질 위험이 있는 곳은 따로 막는 편이 안전합니다.

{{< callout kind="note" title="진입 방지 테이프가 들어 있는 모델이라면" >}}
일부 예전 삼성 로봇청소기에는 **진입 방지 테이프**가 들어 있습니다. 삼성전자서비스 안내(2019)는 들어가지 않길 바라는 구간 **15cm 앞에**, 끊지 않고 이어서 붙이라고 합니다. 약 5cm 미만 단차, 난간·계단 입구, 약 1cm보다 높은 문턱이 있는 방 입구 등에 쓰라고 적혀 있습니다. 내 모델에 테이프가 있는지는 설명서로 확인하세요.
{{< /callout >}}

## 맵이 이상하게 나왔다면

{{< check title="맵을 다시 그리기 전에 확인할 것" >}}
1. 충전기를 맵 그린 뒤에 **45도 이상 돌리거나 1m 이상 옮겼는지** — 그렇다면 맵 삭제 후 공간학습 다시
2. 충전기가 **좁은 통로·방문 근처**에 있지 않은지 — 있으면 자리를 옮기고 맵을 다시
3. 맵에서 빠진 방의 **문이 닫혀 있었거나 입구에 장애물**이 있었는지
4. 충전기 **전원 표시등이 켜져 있는지** — 꺼져 있으면 같은 콘센트에 다른 기기를 꽂아 콘센트부터 확인
{{< /check >}}

맵을 지우고 다시 만드는 일반적인 순서와 로보락 등 다른 브랜드는 [로봇청소기 맵 초기화 방법](/posts/로봇청소기-맵-초기화-방법-지도-재생성-완벽-가이드-2026/)에 정리했습니다. 맵은 잘 그려졌는데 스마트싱스 연결이 안 되면 [로봇청소기 Wi-Fi 연결 안될 때 해결법](/posts/로봇청소기-wi-fi-연결-안될-때-해결법-완벽-가이드-2026/)을 보세요.

{{< callout kind="stop" title="이럴 땐 서비스 점검을" >}}
충전기 자리와 장애물을 정리하고 맵을 다시 만들어도 **같은 공간을 계속 청소하지 못하면**, 삼성전자서비스는 제품 상태를 확인하기 위해 엔지니어 점검을 받으라고 안내합니다(고객센터 1588-3366).
{{< /callout >}}

## 왜 이렇게 썼나

이 글의 7월 판은 리뷰를 AI로 요약해 만든 글이었습니다. 2026-11-12 에 삼성전자서비스 안내와 대조해 다시 썼습니다.

- **맵 만드는 방법을 고쳤습니다.** 7월 판은 «맵 관리 → 새 맵 만들기 → 전체 청소 모드로 첫 맵핑»이라고 적었지만, 삼성전자서비스 안내는 **«맵 관리 → (맵 삭제) → 공간학습 → 시작»**이고 로봇이 청소 없이 먼저 돌아다니며 맵을 그립니다.
- **근거 없는 숫자를 뺐습니다.** «맵핑 실패의 70%는 환경 준비 부족», «전체 청소 모드면 정확도 80% 이상», «만족도 35% 더 높음», «맵핑 오류의 60%는 Wi-Fi», «배터리 효율 30%», «15~30분», «맵 최대 3~4개» 같은 숫자는 확인할 수 있는 근거가 없어 지웠습니다.
- **충전기 거리를 삼성 값으로 바꿨습니다.** 7월 판은 «도킹 주변 1m», «공유기에서 5m 이내»라고 적었습니다. 삼성 안내는 충전기 **좌우 0.5m·앞 1m**이고, 공유기 거리 기준은 찾지 못했습니다.
- **충전기를 옮긴 뒤의 기준을 넣었습니다.** «가구 이동 후 즉시 맵 재생성» 대신, 삼성이 밝힌 **«청정스테이션 45도 이상 회전·1m 이상 이동»** 기준을 적었습니다.
- **확인되지 않은 기능 설명을 뺐습니다.** «임시·영구 금지 구역», «빅스비 음성 명령 예시», «조명이 어두우면 라이다가 벽을 오인식» 같은 내용은 삼성 자료에서 확인하지 못했습니다.
