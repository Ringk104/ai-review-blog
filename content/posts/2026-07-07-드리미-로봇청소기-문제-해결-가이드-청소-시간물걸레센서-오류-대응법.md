{{< action title="드리미가 이상하면, 먼저 이것부터" >}}
1. 바닥의 **전선·슬리퍼**를 치우고, 청소할 방의 **문을 연다**
2. 바닥이 **젖어 있지 않은지** 본다 — 젖은 바닥에서는 바퀴가 미끄러져 동선이 흐트러진다
3. 범퍼 창과 **라인 레이저 센서**를 부드러운 천으로 닦는다
4. 스테이션 문제라면 **오수통·세척판 필터·먼지 봉투**부터 확인한다
{{< /action >}}

드리미 올인원 모델은 로봇과 스테이션이 함께 일하기 때문에, 문제가 로봇 쪽인지 스테이션 쪽인지 나눠 보면 빨리 풀립니다. 오류 알림 문장별 조치는 [드리미 오류코드 총정리](/posts/드리미-오류코드-총정리-에러-표시별-대응법-2026/)에, 와이파이 문제는 [드리미 네트워크 연결 오류 점검 순서](/posts/드리미-네트워크-연결-오류-점검-순서/)에 따로 정리했습니다.

## 1. 청소가 덜 되거나, 방을 빠뜨리거나, 동선이 이상할 때

{{< check title="드리미 X50 Ultra 설명서 기준" >}}
1. **방을 빠뜨림** → 청소할 방의 문이 열려 있는지 확인. 방 입구 바닥이 젖어 미끄러우면 로봇이 제대로 움직이지 못하니 말린 뒤 다시
2. **정해 준 경로대로 안 움직임** → 전선·슬리퍼 같은 물건 정리, 젖은 바닥 말리기, 범퍼 창과 3D 라인 레이저 센서를 깨끗하고 부드러운 천으로 닦기
3. **소리가 커짐** → 먼지통 필터가 막혔는지(청소·교체), 메인 브러시나 먼지통에 딱딱한 물건이 끼었는지, 메인 브러시·사이드브러시 엉킴 확인 · 흡입 모드를 «Standard»나 «Quiet»로 바꾸기
4. **충전 뒤 이어서 청소하지 않음** → 방해 금지(DND) 모드인지 확인 · 손으로 스테이션에 올리거나 앱·버튼으로 충전을 보낸 경우는 원래 이어서 하지 않음
{{< /check >}}

청소 시간이 길게 느껴질 때는 앱에서 **걸레 세척 주기**를 확인해 봅니다. 설명서에 따르면 로봇은 청소 중 앱에서 정한 주기에 맞춰 **스테이션으로 돌아가 걸레를 빨고 물을 채운 뒤** 청소를 이어 갑니다. 물걸레질 전에는 **걸레를 먼저 빨기** 때문에 출발이 늦을 수 있다는 점도 설명서에 적혀 있습니다.

## 2. 걸레가 빠지거나, 걸레 받침이 들릴 때

{{< check title="걸레가 청소 중 빠질 때 (드리미 고객지원)" >}}
1. 걸레를 오래 썼다면 **새 걸레로 바꿔** 나아지는지 본다
2. 그래도 빠지면 **걸레 받침의 자석**을 확인 — 왼쪽·오른쪽 걸레를 바꿔 끼워 시험해 본다
3. **정품 드리미 걸레**를 쓰는지 확인 — 정품이 아니면 정품으로 바꿔 보라고 안내
4. 자석에 녹이 있거나 자력이 약하면 걸레 받침 교체 대상
5. 그래도 안 되면: 로봇을 스테이션에서 내림 → 걸레 받침을 뗌 → 로봇을 **수동으로 재시작** → 정상이 되면 걸레 받침을 다시 끼움
{{< /check >}}

- 걸레 받침이 **비정상적으로 들려 있으면** 받침을 빼서 걸린 것을 확인하고 로봇을 재시작합니다. 계속되면 고객지원에 문의합니다(X50 Ultra 설명서).
- 걸레가 없는 채로 청소하는 것은 고장이 아닐 수 있습니다. X50 Ultra는 앱에서 **흡입 기능**이나 **흡입 후 물걸레** 기능을 켜면 스테이션에서 **걸레 받침을 떼어 두고** 흡입부터 합니다. 흡입이 끝나면 돌아와 걸레를 다시 끼우고 물걸레질을 합니다.

## 3. 스테이션 — 먼지 비움·세척판·물 고임

{{< check title="스테이션 점검 (X50 Ultra 설명서)" >}}
1. **먼지를 자동으로 못 비움** → 먼지 봉투가 가득 찼는지 확인 · 차지 않았다면 로봇·스테이션·먼지통의 **자동 비움 통로**에 막힌 곳이 없는지 확인해 청소 · 앱에서 자동 비움이 꺼져 있으면 비우지 않음
2. **세척판 수위 이상** → 오수통 마개(실링)가 헐겁거나 잘못 끼워졌는지 확인해 다시 끼우기 · 오수통을 지그시 눌러 제대로 장착 · **세척판 필터를 빼서 오수 배출구**가 막혔는지 확인·청소 · 정품 세정액 외의 액체를 넣지 않았는지 확인
3. **깨끗한 물통 아래나 실링 주변에 물이 있음** → 물통을 뺄 때 관에 남은 물이 떨어진 것으로 **정상**. 마른 천으로 닦기
4. 스테이션 상태 표시등이 **주황색으로 켜져 있으면** 스테이션 오류
{{< /check >}}

{{< callout kind="warn" title="작동 중에는 스테이션을 건드리지 마세요" >}}
X50 Ultra 설명서는 작동 중에 **스테이션, 깨끗한 물통, 오수통, 세척판 필터를 옮기거나 빼지 말라**고 적습니다. 온수 걸레 세척을 켜 둔 경우에는 화상을 입지 않도록 물 나오는 곳을 만지지 말라고도 합니다.
{{< /callout >}}

## 4. 물걸레 냄새

- 설명서는 로봇이 일을 마친 뒤 **오수통을 씻어 냄새를 막으라**고 적습니다. 정기 관리 표에서도 오수통은 **쓸 때마다** 관리 대상입니다.
- **세척판 필터는 1~2개월마다** 깨끗한 물로 헹궈 닦은 뒤 다시 끼웁니다.
- 스테이션은 청소를 마치고 돌아오면 먼지를 비운 뒤 **걸레를 빨고 말립니다.**
- 걸레는 **1~3개월마다** 교체합니다.

## 5. 스테이션 앞에서 멈추고 못 들어갈 때

{{< check title="스테이션으로 못 돌아갈 때 (X50 Ultra 설명서)" >}}
1. 스테이션 **양옆과 앞에 공간**이 충분한지
2. 돌아오는 길이 **닫힌 문** 등으로 막히지 않았는지
3. 스테이션 앞 바닥이 **젖어서** 로봇이 미끄러지지 않는지 — 물기를 닦고 다시
4. **경사판 연장판**이 제대로 끼워졌는지
5. 그래도 안 되면 스테이션을 다른 자리로 옮겨 다시 시도
6. 로봇을 손으로 멀리 옮겼다면 위치를 다시 잡느라 못 돌아올 수 있으니 손으로 스테이션에 올려 두기 · 스테이션 **신호부**의 먼지 닦기
{{< /check >}}

## 왜 이렇게 썼나

이 글의 7월 판은 리뷰를 AI로 요약해 만든 글이었습니다. 2026-11-15 에 드리미 공식 자료와 대조해 다시 썼습니다.

- **근거 없는 비율을 뺐습니다.** «청소 시간 지연 약 25%», «걸레 빠짐 약 20%», «맵핑 오류 약 18%», «쉰내 약 15%», «배수 호스 약 12%»는 후기 언급 빈도를 추정한 값이라 지웠고, 이 비율을 그린 그림들도 함께 뺐습니다.
- **확인되지 않은 앱 설정을 지웠습니다.** «충돌 방지 모드 끄기», «낮은 통과 공간 청소 회수 밸런스», «열풍 건조 최대 4시간», «클라우드 동기화 토글» 같은 설정 이름·값은 드리미 자료에서 확인하지 못했습니다.
- **배수 호스 조언을 뺐습니다.** «여유분 10cm만 남기고 자르기»는 근거가 없습니다. X50 Ultra의 자동 급배수 키트는 따로 사야 하고 일부 지역에서만 판다고 설명서에 적혀 있어, 설치는 판매처 안내를 따르는 것이 안전합니다.
- **교체 주기를 드리미 값으로 바꿨습니다.** 7월 판의 «걸레 3~6개월 점검», «30도 이하 단독 세탁» 대신 설명서의 «걸레 1~3개월» 등 정기 관리 표를 옮겼습니다.
- **증상 중심으로 다시 묶었습니다.** 로봇 쪽(동선·소리·걸레)과 스테이션 쪽(먼지 비움·세척판·복귀)을 나눠, 어디를 봐야 하는지 바로 알 수 있게 했습니다.
