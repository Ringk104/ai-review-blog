## 1. ThinQ 앱 등록이 안 될 때 (Wi-Fi)

LG전자는 ThinQ 로고가 있는 모델만 ThinQ 앱에 연결할 수 있다고 안내합니다(코드제로 R9 안내). 등록 전에 아래를 먼저 맞춥니다.

{{< check title="등록 전에 (LG 코드제로 R9 안내)" >}}
- 제품과 공유기의 **전원이 켜져 있는지** 보고, 둘 사이를 **가깝게** 한다
- 스마트폰의 **모바일 데이터**(아이폰은 **셀룰러 데이터**)를 끄고, 지금 쓰는 **공유기 Wi-Fi** 에 연결한다
- ThinQ 앱을 설치하고 필요한 **접근 권한**을 허용한다
- 앱에서 등록할 때는 **스마트폰과 같은 Wi-Fi** 를 고른다 — **5G Wi-Fi 에는 제품이 연결되지 않는다**
{{< /check >}}

제품을 «연결 준비» 상태로 만드는 버튼은 모델마다 다릅니다.

- **코드제로 R9**: 제품의 **[터보] 또는 [Wi-Fi] 버튼을 3초 이상** 누릅니다(제품마다 버튼 위치가 다를 수 있음).
- **로보킹 AI 올인원**: 덮개를 열고 전원을 켠 뒤 **[시작/정지]와 [충전] 버튼을 동시에 3초 이상** 누릅니다. 음성 안내가 나오고 LED가 깜박이면 준비된 것입니다. 앱에서 Wi-Fi 를 고르고 비밀번호를 넣어 **[연결하기]** 를 누른 뒤, **100%** 가 되고 완료음이 들릴 때까지 기다립니다. 아이폰은 중간에 스마트폰 Wi-Fi 설정에서 제품이 만든 네트워크를 골라야 하고, 비밀번호는 **제품 식별자 마지막 네 자리를 두 번 이어 쓴 것**입니다.
- **로보킹 옛 모델**(R76·R46 시리즈, VR648 시리즈): 전원을 켠 뒤 **[터보] 버튼을 3초 이상** 누르고, 아이폰은 Wi-Fi 목록에서 **LG_HOMBOT_REG** 에 연결합니다.

![ThinQ 앱 등록이 안 될 때 세 가지 — 모바일 데이터 끄고 스마트폰을 공유기 Wi-Fi에 연결, 5G Wi-Fi에는 연결되지 않으니 2.4GHz로(로보킹), 연결 준비 버튼 3초 이상(R9는 터보·Wi-Fi 버튼, 로보킹 AI 올인원은 시작/정지와 충전 동시에)](/images/art_lgrobo_wifi.svg)

그래도 등록이 안 되면, LG전자가 로보킹 옛 모델(R76·R46·VR648 시리즈) 안내에 적은 확인 항목을 봅니다.

{{< check title="등록이 안 될 때 (LG 로보킹 R76·R46·VR648 시리즈 안내)" >}}
- 이 제품은 **2.4GHz Wi-Fi 만** 지원한다 — 공유기 주파수는 인터넷 서비스 업체나 공유기 설명서로 확인한다
- 공유기 **Wi-Fi 이름(SSID)** 은 영문·숫자로 정한다
- 신호가 약하거나 자주 끊기면 공유기를 **제품 가까이** 옮긴다
- 공유기에 **방화벽**이 있으면 예외로 등록하거나 해제한 뒤 진행한다
- 처음 등록한 뒤 **공유기를 바꿨거나 비밀번호를 바꿨다면**, 앱에서 제품을 **삭제하고 다시 등록**한다
{{< /check >}}

공유기 쪽 점검은 [로봇청소기 Wi-Fi 연결 안될 때 해결법](/posts/로봇청소기-wi-fi-연결-안될-때-해결법-완벽-가이드-2026/)에 더 자세히 정리했습니다.

## 2. 충전대로 안 돌아올 때

LG 코드제로 R9 안내는 **충전대 전원 플러그가 빠졌거나 복귀 경로에 장애물이 있으면** 돌아오지 못할 수 있다고 적습니다. 로보킹은 충전대로 돌아오지 못하면 **[ER06]** 을 표시합니다.

{{< check title="충전대 복귀 (LG 코드제로 R9 · 로보킹 안내)" >}}
- 충전대 표시등을 본다 — 코드제로 R9·M9 는 **충전대 위쪽 LED에 파란 불빛**이 들어와야 한다. 충전대 앞 **보호 비닐**이 붙어 있으면 떼고, 멀티탭이면 **차단 스위치**도 본다
- 장애물을 치운다 — R9 는 **좌우 최소 50cm, 전면 1m 이상**, 로보킹(ER06 안내)은 **정면 2m, 좌우 1.5m**
- 충전대는 **평평한 바닥에 벽에 닿게** 두고, **하이글로시 가구·거울·유리**나 **직사광선**이 드는 곳은 피한다(R9)
- 청소는 **충전대에 있는 상태에서 시작**한다 — 충전대 위치를 알아 복귀가 쉬워진다
- 로봇과 충전대의 **금속 단자**를 마른 걸레나 지우개로 닦고, 로봇의 **신호 감지 센서·먼지 센서**의 먼지를 없앤다(R9)
{{< /check >}}

코드제로 M9 는 충전대를 찾지 못하면 **방 전체 벽을 따라 충전대를 찾는 것이 정상 동작**이라고 LG는 안내합니다. 거리와 순서는 [로봇청소기 도킹 실패 해결법](/posts/로봇청소기-도킹-실패-해결법-충전대-복귀-안될-때-5가지-점검법-2026/)에 자세히 정리했습니다.

## 3. 충전대에 있는데 충전이 안 될 때

{{< check title="충전 안 됨 (LG 로봇청소기 R9 안내)" >}}
- 충전대의 **충전 표시등 램프가 꺼져 있으면** 단자끼리 닿지 않은 것이다 — 로봇을 뺐다가 다시 끼운다
- 단자를 닦을 때는 **전원 플러그부터 뽑고**, **힘을 너무 주지 않으며**, **시너·솔벤트·아세톤** 같은 유기 용제는 쓰지 않는다
- 배터리가 다 닳았다면 로봇을 **충전대 정면에 맞춰 끼워** 충전한다
- **5°C 이하**에서는 충전이 안 될 수 있다 — 실내에서 충전한다
{{< /check >}}

코드제로 R5 는 **주 전원 스위치가 꺼져 있으면** 충전은 되지만 앱의 배터리 %가 바뀌지 않고, LED가 **분홍색으로 계속 깜박인다**고 LG는 안내합니다. 주 전원 스위치를 켜면 전원이 완전히 켜지기까지 **17초**가 걸립니다.

LG는 **하루 종일 충전해도 표시등이 깜박이며 계속 충전 중**이라면 청소기나 어댑터 이상일 수 있다며 서비스를 받으라고 안내합니다(R9). 자세한 순서는 [로봇청소기 충전 안됨 해결법](/posts/로봇청소기-충전-안됨-해결법-도킹-실패-원인-5가지-2026/)에 있습니다.

## 4. 도면이 이상하거나 사라질 때

ThinQ 앱에서 도면을 그리기 전에 LG는 네 가지를 확인하라고 안내합니다. 로봇이 **충전대에 있고**, **충분히 충전**되어 있고, 움직임을 막는 **장애물이 없고**, 실내가 **충분히 밝아야** 합니다. 도면은 앱 홈 화면의 로봇청소기 제품 카드에서 **[도면 그리기]** 로 만들고, 연필 아이콘으로 들어가는 **마이존**에서 **방 편집**(영역 나누기·합치기)과 **청소 금지 영역 설정**을 합니다.

도면이 자꾸 사라진다면 전원을 끄는 방법을 봅니다. 아래는 **코드제로 R5** 안내입니다.

{{< check title="도면이 사라질 때 (LG 코드제로 R5 안내)" >}}
- **주 전원 스위치**를 껐다 켜면 저장된 **도면·금지 영역·흡입 모드·물 공급 모드 설정**이 초기화된다
- 설정을 남기려면 **충전대 밖에서 상단 전원 버튼을 5초** 눌러 끈다 — 이렇게 끈 뒤에는 주 전원 스위치를 껐다 켜도 저장한 설정으로 돌아온다
- **[충전] 버튼을 15초 이상** 누르면 공장 초기화다 — 저장한 설정과 **ThinQ 앱 연결까지 모두** 초기화된다
- 청소 뒤 **충전대로 돌아오지 않으면** 도면은 미완성 상태로 저장된다
{{< /check >}}

![도면이 사라졌다면 끄는 방법 확인(LG 코드제로 R5) — 주 전원 스위치를 껐다 켜면 도면·금지 영역이 초기화되고, 충전대 밖에서 상단 전원 버튼 5초로 끄면 저장한 설정이 남고, 충전 버튼 15초 이상은 앱 연결까지 공장 초기화](/images/art_lgrobo_map.svg)

도면은 있는데 한곳만 맴돌거나 엉뚱하게 움직인다면, LG 코드제로 R9 안내는 **어두운 곳(20lux 미만)**, **하이그로시·유리·스테인리스처럼 반사가 심한 곳**, **직사광선**을 원인으로 듭니다. 금지 영역은 너무 가깝게 여러 개 그리면 청소가 미흡한 곳이 생길 수 있고, 코드제로 R5 안내는 앱 화면의 **1mm 가 실제로는 15cm 이상** 차이 날 수 있으니 금지 영역을 넉넉하게 그리라고 합니다. 자세한 내용은 [로봇청소기 특정 구역 안감 해결법](/posts/로봇청소기-특정-구역-안감-해결법-매핑-오류-완벽-가이드-2026/)에 정리했습니다.

## 5. 에러 음성이 나올 때 — 스마트진단

LG 로봇청소기는 문제가 생기면 **볼 곳을 음성으로** 알려 줍니다. 음성이 말한 곳부터 봅니다.

{{< check title="«바퀴를 확인해 주세요» (LG 로보킹 안내)" >}}
- 바퀴가 주행할 수 없는 상태가 감지되면 나온다 — **현관·발코니·계단**에 바퀴가 빠져 있다면 **평평한 바닥**으로 옮긴다
- 아니라면 **먼지통을 먼저 빼고**, 부드러운 천 위에 뒤집어 바퀴에 감긴 **이물**을 뺀다
- 로보킹에 **걸레를 달고** 쓰다 «걸레를 부착하였다면 바퀴 확인을 해 주세요» 음성이 나오면, 젖은 걸레와 바닥의 마찰 때문일 수 있다 — **걸레판을 떼고** 돌려 보고, 괜찮으면 **마른 걸레**로 쓴다
{{< /check >}}

바퀴에 감긴 것을 빼는 자세한 방법은 [로봇청소기 바퀴 엉킴 해결법](/posts/로봇청소기-바퀴-엉킴-해결법-브러시-머리카락-제거-2026/)에 있습니다.

어디가 문제인지 모르겠다면 **코드제로 R9** 은 **스마트진단**으로 센서·모터 같은 부품을 스스로 점검합니다.

{{< check title="스마트진단 (LG 코드제로 R9 안내)" >}}
- 로봇을 **충전대 위에서 충전 중**인 상태로 두고(배터리 표시 **1칸 이상**), **먼지통을 끼우고**, 바퀴가 **들리지 않게** 한다
- 로봇 **주변 1m 안**의 물건을 치운다. 카펫 위나 광택이 심한 바닥에서는 결과가 잘못될 수 있다
- 리모컨의 **[스마트진단]** 버튼을 누르면 로봇이 **약 50cm** 움직이며 점검하고 결과를 음성으로 알려 준다
- 결과는 **[충전]** 버튼을 누르면 다시 들을 수 있다. 끝나고 **약 1분** 뒤 충전대로 돌아가 충전한다
{{< /check >}}

결과 음성은 «장애물 감지 센서창을 닦아 주세요», «하부 낭떠러지 감지 센서를 닦아 주세요», «먼지통과 필터를 청소해 주세요», «회전 브러시에 이물질이 끼었는지 확인해 주세요»처럼 볼 곳을 알려 줍니다. LG는 **장애물 감지·초음파·낭떠러지 감지 센서**에 이상이 있으면 로봇이 충전대로 돌아오지 않고 음성만 알린 뒤 진단을 끝낸다고 안내합니다. 다른 모델의 오류 표시는 [로봇청소기 오류코드 총정리](/posts/로봇청소기-오류코드-총정리-브랜드별-에러-해결법-2026/)의 LG 부분을 참고하세요.

## 6. 회전솔이 안 돌 때

LG는 측면·바닥 회전솔 틈새로 **머리카락 같은 이물이 감기면** 회전솔이 돌지 않을 수 있다고 안내합니다. 회전솔을 빼는 방법은 모델마다 다릅니다.

- **로보킹 — 측면 회전솔**: **십자드라이버**로 가운데 나사를 **시계 반대 방향**으로 돌려 빼고, 청소용 솔로 이물을 없앤 뒤 따뜻한 물에 씻습니다. 좌우 회전솔은 조립부 모양이 달라 **L·R 표시**를 보고 끼웁니다. 나사가 헛돌면 서비스 점검을 받습니다.
- **로보킹 — 주 회전솔**: 회전솔 커버 위의 **후크**를 누른 채 앞으로 당겨 빼고, 회전솔을 **노란색 쪽으로 밀면서** 위로 올려 뺍니다. 많이 엉켰으면 청소용 솔이나 가위로 자르되 솔이 잘리지 않게 합니다. 솔이 휘었다면 **따뜻한 물에 10초** 담갔다가 손으로 폅니다.
- **코드제로 R9**: 천 위에 뒤집고, 흡입구 왼쪽의 **회전솔 분리 버튼**으로 회전솔과 덮개를 뺀 뒤, **회전솔 분리 레버**를 누른 채 회전솔을 들어 올립니다. 손상된 솔은 미지근한 물에 적신 수건으로 **1시간 이상** 감쌌다가 그늘에서 말립니다. 조립은 **오른쪽부터** 끼우고 덮개를 **«딸깍»** 소리가 날 때까지 누릅니다.

![회전솔이 안 돌 때 빼서 감긴 것 없애기 — 측면 회전솔은 십자드라이버로 나사를 풀고(로보킹), 주 회전솔은 노란색 쪽으로 밀며 올려 빼고(로보킹), R9는 분리 버튼과 분리 레버로 뺀다. 측면 회전솔은 L·R을 구분해 조립, R9는 딸깍 소리가 날 때까지 눌러 닫는다](/images/art_lgrobo_brush.svg)

브러시에 머리카락이 자주 감긴다면 [로봇청소기 브러시 엉킴 예방·제거](/posts/로봇청소기-브러시-엉킴-예방제거-완벽-가이드-머리카락-관리법-2026/)도 참고하세요.

## 7. 흡입력이 약하거나 소리가 클 때

{{< check title="흡입력·소음 (LG 로봇청소기 R9 안내)" >}}
- **먼지통**이 가득 차면 흡입력이 떨어지고 소리가 커질 수 있다 — 비우고, 먼지 분리기와 필터는 씻었다면 **그늘에서 24시간 이상** 말린다
- **필터를 빼고 쓰지 않는다** — 모터에 먼지가 들어가 고장 날 수 있다
- 흡입구가 **휴지·스타킹·비닐봉지**로 막혔는지 보고 막대로 빼낸다
- **터보·스마트 터보**를 쓰면 흡입력이 세지는 만큼 소리도 커질 수 있다 — 고장이 아니다
{{< /check >}}

LG는 로봇청소기가 **회전솔로 쓸어 담은 뒤 흡입하는 방식**이라, 젖어서 바닥에 붙은 이물·정전기가 생기기 쉬운 머리카락·쌀알 같은 것은 청소가 잘 안 될 수 있다고 설명합니다(R9). 로보킹은 바퀴 쪽 **스프링**이 충격을 받으며 나는 소리는 정상이라고 안내하고, 앞바퀴(전방 캐스터)에 이물이 끼었다면 **일자 드라이버**로 빼서 청소하라고 합니다.
