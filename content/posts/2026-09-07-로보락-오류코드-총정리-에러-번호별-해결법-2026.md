> 이 글은 로보락 공식 사용설명서(S7 영문판의 «Errors» 표, Qrevo 2 Pro 영문판의 «Common Issues» 표)를 바탕으로 AI가 정리하고 운영자가 확인했습니다. 2026-11-10 에 전면 다시 썼습니다 — 고친 이유는 아래 «왜 이렇게 썼나»에 있습니다.

{{< action title="로보락이 빨간 불과 함께 멈췄다면, 이 순서로" >}}
1. 앱 알림이나 음성 안내로 **오류 번호·내용**을 확인한다
2. 아래 표에서 번호를 찾아 그 부품을 **전원을 끄고** 청소·정리한다
3. 로봇을 다른 자리로 옮겨 **다시 청소를 시작**한다
4. 그래도 같은 오류가 나면 **시스템 재설정** 후 고객지원에 문의한다
{{< /action >}}

로보락 설명서에 따르면 청소 중 오류가 나면 **전원 표시등이 빨간색으로 빠르게 깜박이고 음성 안내가 나옵니다.** 최신 모델은 앱에도 알림이 뜹니다. 오류 상태로 10분 넘게 두면 로봇은 스스로 절전 상태로 들어갑니다(Qrevo 2 Pro 설명서).

설명서가 모든 오류에 공통으로 적는 원칙은 세 가지입니다.

- 오류를 해결한 뒤에는 **로봇을 다른 자리로 옮겨** 청소를 다시 시작합니다.
- 센서 오류는 **센서를 닦고** 다시 해 봅니다.
- 배터리 온도 이상이면 **온도가 정상으로 돌아올 때까지 기다린 뒤** 씁니다.

## 번호로 알려 주는 모델 — 공식 오류표

아래는 로보락 S7 공식 사용설명서의 오류표를 그대로 옮긴 것입니다. 오류 번호로 알려 주는 모델이라면 같은 번호를 쓰는 경우가 많지만, **모델마다 다를 수 있으니 내 모델 설명서와 함께 보세요.** 번호가 비어 있는 곳(10·11·19·20·24\~26)은 설명서 표에 없는 번호입니다.

| 번호 | 뜻 | 조치 |
|---|---|---|
| Error 1 | 라이다(상단 레이저) 탑 또는 레이저가 막힘 | 가린 것이 없는지 확인하고 다시 시도 |
| Error 2 | 범퍼가 눌린 채 걸림 | 범퍼를 닦고 가볍게 두드려 풀기 |
| Error 3 | 바퀴가 바닥에서 들림 | 로봇을 옮기고 다시 시작 |
| Error 4 | 절벽 센서 오류 | 절벽 센서를 닦고, 계단·턱 같은 낙차에서 떼어 다시 시작 |
| Error 5 | 메인 브러시 걸림 | 메인 브러시와 베어링 청소 |
| Error 6 | 사이드브러시 걸림 | 사이드브러시를 빼서 청소 |
| Error 7 | 바퀴 걸림 | 로봇을 옮기고 다시 시작 |
| Error 8 | 로봇이 갇힘 | 로봇 주변 장애물 치우기 |
| Error 9 | 먼지통 없음 | 먼지통과 필터 끼우기 |
| Error 12 | 배터리 부족 | 충전 후 다시 시도 |
| Error 13 | 충전 오류 | 충전 접점을 닦고 다시 시도 |
| Error 14 | 배터리 오류 | (설명서에 조치 없음 — 고객지원 문의) |
| Error 15 | 벽 감지 센서 더러움 | 벽 감지 센서 닦기 |
| Error 16 | 로봇이 기울어짐 | 평평한 바닥으로 옮겨 다시 시작 |
| Error 17 | 사이드브러시 오류 | 로봇 재설정 |
| Error 18 | 팬(흡입 모터) 오류 | 로봇 재설정 |
| Error 21 | 위쪽 범퍼가 눌림 | 로봇을 옮기고 다시 시도 |
| Error 22 | 도크 위치 표지 오류 | 닦고 다시 시도 |
| Error 23 | 도크로 돌아가지 못함 | 도크의 위치 표지 부분을 닦고 다시 시도 |
| Error 27 | 물걸레 들어올림 장치(VibraRise) 걸림 | 걸린 것이 없는지 확인 |
| Error 28 | 로봇이 카펫 위에 있음 | 로봇을 바닥으로 옮겨 다시 시도 |

설명서 표에는 번호 없이 문장으로만 나오는 오류도 있습니다.

- **필터가 막혔거나 젖음** → 필터를 청소하고 **완전히 말린 뒤** 다시 시도
- **금지 구역·가상 벽 안에 있음** → 로봇을 그 구역 밖으로 옮기기
- **카펫을 넘지 못함** → 로봇을 카펫 건너편으로 옮겨 다시 시작
- **내부 오류** → 로봇 재설정

{{< callout kind="note" title="재설정은 마지막에" >}}
설명서는 «시스템 재설정으로 해결되는 문제도 있다»고 적습니다. 다만 재설정하면 예약 청소·와이파이 같은 설정이 공장 상태로 돌아갈 수 있으니(Qrevo 2 Pro 설명서), 표의 조치를 먼저 해 본 뒤에 합니다. 재설정 버튼 위치와 누르는 방법은 모델마다 달라 이 글에 적지 않았습니다 — 내 모델 설명서를 보세요.
{{< /callout >}}

## 번호 없이 알려 주는 최신 모델(Qrevo 계열)

Qrevo 2 Pro 설명서에는 번호가 붙은 오류표가 없습니다. 대신 오류가 나면 **전원 표시등이 빨간색으로 깜박이거나 상태 표시등이 빨간색으로 켜지고, 앱에 알림이 뜨며 음성 안내가 나올 수 있다**고 적습니다. 앱 알림에 나온 문장을 그대로 보고, 설명서의 «Common Issues» 표에서 같은 증상을 찾는 것이 순서입니다. 자주 찾는 항목만 옮깁니다(아래 표의 조치는 모두 Qrevo 2 Pro 설명서 문구).

{{< check title="도크 상태 표시등이 빨간색으로 켜져 있을 때 (Qrevo 2 Pro 설명서)" >}}
1. 콘센트 전압이 도크에 적힌 조건에 맞는지 확인
2. 깨끗한 물통이 제자리에 있는지, 물이 충분한지 확인
3. 오수통이 제자리에 있는지, 비워야 하는지 확인
4. 세척 트레이와 트레이 필터가 제대로 끼워졌는지 확인
{{< /check >}}

| 증상 | 조치 |
|---|---|
| 충전이 안 됨 | 전원선 양쪽 연결 확인 · 도크와 로봇의 충전 접점 닦기 · 상태 표시등이 켜졌는지 확인 |
| 도크로 돌아가지 못함 | 도크 주변 장애물 치우거나 도크를 트인 곳으로 옮기기 · 로봇을 도크 가까이 두고 다시 시도 |
| 손으로 옮긴 뒤 도크로 못 감 | 위치가 크게 바뀌면 지도를 다시 만들기 때문 — 도크가 멀면 손으로 도크에 올려 두기 |
| 이상하게 움직임 | 로봇 다시 켜기 |
| 와이파이 연결 안 됨 | 와이파이 재설정 후 다시 · 신호 좋은 곳으로 옮기기 · 앱 최신 버전으로 |
| 청소하다 군데군데 빠뜨림 | 벽 감지·절벽·카펫 센서를 부드럽고 마른 천으로 닦기 |
| 물걸레에 물이 적거나 안 나옴 | 앱에서 물 양 올리기 |

도크로 돌아오지 않는 문제는 [로보락이 충전 도크로 복귀하지 않을 때](/posts/로보락-충전-도크로-복귀하지-않을-때-점검-순서/)에, 청소 중 소리는 [로보락에서 끼익 소리가 날 때](/posts/로보락-끼익-소리-날-때-점검-순서/)에, 사이드브러시는 [로보락 사이드브러시가 안 돌아갈 때](/posts/로보락-사이드브러시-안-돌아갈-때-점검-순서/)에 순서대로 정리해 두었습니다.

## 브러시·필터 오류가 반복될 때

## 왜 이렇게 썼나

이 글의 9월 판은 리뷰를 AI로 요약해 만든 글이었고, 공식 오류표와 맞지 않는 곳이 많았습니다. 2026-11-10 에 설명서와 한 줄씩 대조해 고쳤습니다.

- **번호의 뜻이 달랐습니다.** 예를 들어 9월 판은 Error 6을 «바퀴», Error 8을 «흡입구 막힘», Error 17을 «위치 추적 실패», Error 23을 «절벽 센서», Error 28을 «사이드브러시»로 적었지만, 설명서에서는 각각 사이드브러시 걸림, 로봇이 갇힘, 사이드브러시 오류, 도크로 돌아가지 못함, 카펫 위에 있음입니다. 설명서 표에 없는 번호(Error 11·26·30\~34)를 설명한 부분은 뺐습니다.
- **원인 비율을 뺐습니다.** «센서 먼지 42%» 같은 비율과 «오류를 70% 줄일 수 있다»는 문장은 확인할 수 있는 근거가 없어 지웠습니다.
- **최신 모델을 따로 다뤘습니다.** Qrevo 2 Pro 설명서에는 번호 오류표가 없어, 번호를 찾지 말고 앱 알림 문장과 «Common Issues» 표를 보라는 안내를 더했습니다.
